# 工作区面板界面细节

本文规定标题栏、标签和内容表面的表现。空间分配、打开意图、最大化、单区、历史与状态所有权以 [主窗口工作区、历史面板与标题栏](README.md) 为准；响应式布局已实现，本次原生与测试覆盖范围见 README 文末，不把旧浮层面板的验证结果视为新布局验收。

## 标题栏分段

```text
并排：[侧栏][新建*] | 会话标题 ⋯ [历史] | [文件 ×][Git ×][改动 ×] + … [最大化][工作区]
单区：[侧栏][新建*] | [返回对话] [文件 ×][Git ×] + … [最大化/还原][工作区]
                                              * 仅侧栏收起时显示
```

- 标题栏使用外层分配的同一矩形，与正文边界对齐；不通过标签内容或导航宽度再算一次分界。
- 并排时标签、`+`、全部标签、最大化与工作区开关在工作区段，历史开关在对话段。工作区隐藏或对话单区时，打开工作区入口留在对话段。
- 工作区独占时不保留一个压扁的对话标题段，提供明确的返回对话入口。手动最大化显示还原动作，自动单区的返回不伪装成“关闭工作区”。具体操作遵循 README。
- 标签间和空白区域保留平台窗口拖动与双击行为；按钮与标签本身不触发窗口拖动。窄时先缩短文字并使用溢出菜单，保留返回、关闭和当前标签的可达性。
- 不渲染工作区浮窗顶部的第二套标签栏，不使用遮罩、悬浮阴影或露出一条被截断的对话作为返回入口。

## 标签与启动器

- 文件、Git、各轮改动都是普通可关闭标签。文件与 Git 复用本对话已有标签，改动沿用每个 Run 的身份规则；`+` 创建启动器标签，选择已有工具时激活已有标签并移除该启动器。全部关闭后保留启动器，工作区不自动关闭。
- 使用标准桌面标签，选中、悬停、焦点与拖动状态清楚；不用 pill 样式。图标、截断标题与关闭按钮共享对齐基线，关闭槽保留宽度，完整标题可通过提示读取。
- 拖动矩形留在栏内、保持抓取尺寸，越过邻居触发实时换位；邻居采用主题 spring 让位，松手回槽。稳定槽位与视觉动画分离，Capture 收尾与命中裁剪遵循 [工作区标签拖拽](../issue-86/README.md#工作区标签拖拽)。布局模式改变按既有失效规则结束手势，不另改排序算法。
- 保留中键关闭、关闭/关闭其他/关闭右侧菜单、横向滚动、当前标签显示和全部标签菜单。空白处不打开标签菜单。
- 启动器使用紧凑工具行与最多 8 项本对话最近记录，不重复大标题或新增装饰卡片。不可用工具或不能恢复的最近记录说明原因，不发起模型请求。
- 启动器与只有树的 Files 都占完整工作区宽度；其视觉内容可以采用舒适宽度，但不得缩小外层面板。

## 工作区内部与表面

工作区是平铺区域，与对话只用一条分隔线区分。内部正文/列表分隔属于工作区，不重复画外框或嵌套卡片。历史继续使用自己的内缩卡片，样式和覆盖行为不在本次重设计范围。

- 导航入口位于当前内容头部：Files 使用文件树语义，Git/Changes 使用文件列表语义。自动紧凑时提供“显示文件列表”的明确动作，不把自动隐藏显示成用户已手动关闭。
- 紧凑模式的列表在原面板内部替换正文，并提供返回正文路径；选择文件后展示正文。显示唯一树时不提供把整个内容隐藏的导航开关。
- 内部列表独占、加载、错误和空状态都沿用相同面板表面；不借浮窗逃避窄宽度。缩短路径、折叠低频操作和局部滚动由内容视图负责，不推动外层。
- 源码与差异保留一层文件身份和操作头。Git/Changes 的固定高度头、阅读选项、动作菜单、分组/树导航和差异状态见 [Git 与改动阅读器](../issue-86/README.md)，不在本文复制另一套规则。
- 主题颜色、边框、焦点环、尺寸与动画使用 Kit tokens；焦点和操作命中区域不得因裁剪失效。不为双区与单区切换增加大幅动画。

## 必要视觉验证

响应式布局完成后按 README 的必要验证执行。界面检查集中于：

- 浅色/深色下并排、紧凑和单区的标题/正文边界；长标签和长路径不挤走返回、列表与工作区开关。
- 同宽切换 Files 树、源码、Git、改动、启动器时外边界不动；外分隔可拖，内部列表开关只改变内部。
- 自动隐藏与手动隐藏的入口表达、列表/正文往返焦点、最大化与自动单区的还原行为。
- 既有标签排序、溢出、关闭及空白标题栏操作不因新的区域组合回归。

本次不重复要求历史卡片、回复卡片和无关菜单的全套设计审查。记录真实检查结果与限制，不沿用已失效的浮层截图或历史通过数量。
