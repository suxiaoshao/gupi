# 工作区面板结构调整与界面细节重设计

状态：已实现，工作树待试用。基于已实现的 [主窗口工作区、历史面板与标题栏](README.md)。本方案调整工作区的标签模型与标题栏结构，并对工作区、历史卡片、改动卡片和标题栏做逐项细节审查与重设计。固定/浮窗规则、空间分配、改动标签身份与生命周期、Escape 顺序和临时窗口边界沿用 README，本文只写变化。

## 目标

- 工作区参照 Codex 侧边面板：标签栏进入标题栏，`+` 打开启动器式新标签页，面板可最大化，面板为平铺区域。
- 标签是可用的桌面标签：有明确的形状与状态，可拖动排序，关闭和溢出行为完整。
- 所有可见细节逐项审查，不满足设计规范的重新设计，而不是只调颜色和间距。

不做：终端、侧边聊天、浏览器、Git 等新工具；“推荐”区域；标签跨重启恢复；新增全局快捷键；改动历史卡片之外的对话正文样式。

## 参考

ChatGPT 桌面版（Codex 26.1013）侧边面板：

- 标题栏按区域分段：对话段放会话标题、⋯ 与摘要开关；面板段对齐侧边面板，直接承载标签、关闭与 `+`；窗口右缘是面板最大化与面板开关。面板内容从标题栏下方开始。
- “新标签页”是启动器：“工具”网格（每项图标、名称与快捷键）、“推荐”、“最近”（条目、类型与日期）。文件、变更都是从这里打开的普通标签。
- 面板是平铺区域，以一条细线与对话分隔；只有挂在对话旁的摘要面板使用卡片。

## 设计

### 标题栏分段

```text
[侧栏][新建*] │ 会话标题 ⋯          [历史] │ [文件 ×][改动·修复登录 ×] +  ……  ↗ [工作区]
              │ ←──────── 对话段 ─────────→ │ ←──────────── 工作区段 ────────────────→
```

- 工作区停靠时，标题栏右段宽度与工作区一致，做法与左段跟随侧栏宽度相同（`home/titlebar.rs` 已有带过渡的宽度跟随）。标签栏、`+`、最大化与工作区开关都在右段；分隔线与下方工作区边界对齐。
- 工作区隐藏或为浮窗时没有右段：工作区开关回到对话段右端；浮窗内标签栏位于浮窗顶部。
- 历史开关留在对话段，紧邻工作区段或窗口右侧区域，⋯ 仍紧贴标题。
- 标签之间及标签栏空白处保留窗口拖动区域；双击空白区的行为遵循平台标题栏约定。按钮、标签本身不触发窗口拖动。

### 标签模型：启动器

- 去掉固定的“文件”标签。文件、改动都是普通的可关闭标签；同一对话最多一个文件标签，再次打开时激活已有标签。改动标签沿用 README 的“每个 Run 一个标签”。
- `+` 打开“新标签页”。所有标签关闭后，工作区显示新标签页，不自动隐藏。新标签页本身是一个标签，选择工具后被该工具标签替换。
- 新标签页内容：
  - **工具**：文件（显示已有的打开命令快捷键）、变更（打开最近一个有改动的 Run；没有时禁用并说明原因）。以后的 Git 等工具加在这里。
  - **最近**：本对话最近打开过的文件与改动标签，显示名称、类型与相对时间，最多若干条，不跨重启。没有记录时不显示该组。
- 原先“项目文件”“聚焦源码”等命令改为打开或激活文件标签，其余规则不变。

### 最大化

- 工作区段的最大化按钮让工作区临时占满对话栏所在区域（会话侧栏保持用户状态），再次点击或 Escape 恢复。Escape 顺序插在“关闭内部覆盖”之后、“关闭浮窗”之前。
- 最大化不改写固定偏好、宽度偏好和分隔比例；切换对话、关闭最后一个可见内容或窗口变窄到不能停靠时退出最大化。浮窗状态下不提供最大化。

### 标签设计

- **形状与状态**：圆角标签（使用主题半径，不是直角矩形），区分静止、悬停、选中、焦点和拖动中。选中标签与工作区内容表面相连，未选中标签不画边框；焦点环可见且不被裁切。
- **内容**：类型图标（文件按扩展名或通用文件图标，改动用差异图标）、截断标题、关闭按钮。关闭按钮在选中和悬停时显示，在键盘焦点时可达；不在静止时占位导致标题跳动。
- **宽度**：标签有最小和最大宽度，标题在其中截断，完整标题在提示中。
- **拖动排序**：在标签栏内拖动改变顺序，显示插入位置；拖出标签栏取消。顺序属于该对话的标签状态。
- **关闭**：关闭按钮、中键点击、右键菜单“关闭 / 关闭其他 / 关闭右侧”。关闭后激活规则沿用 README。
- **溢出**：标签栏横向滚动，激活的标签自动滚入视野；保留列出全部标签的下拉菜单。
- 先确认 GPUI Kit `TabBar` / `Tab` 对圆角样式、拖动和中键的支持；不支持的部分在应用内组合实现，不复制组件源码。

### 平铺工作区

工作区使用内容背景，与对话之间只有一条细分隔线，拖动区域不变；去掉多余的内框、重复边框和嵌套卡片。历史面板保持卡片样式。

### 细节审查与重设计

实施前在隔离 gallery 中截取现状（浅色、深色；宽、窄），按 [设计规范](../../../.agents/skills/gpui-kit-design-guides/references/design-guides.md) 的审查清单逐项检查，覆盖：

- 标题栏两段的对齐、按钮间距与尺寸、图标选中态、提示与快捷键。
- 标签栏与新标签页（网格、分组标题、最近列表、禁用说明）。
- 文件标签：树行高、缩进、图标槽、选中与打开标记、空目录、加载与错误；源码头部的文件名、路径、只读标记和操作区。
- 改动标签：文件列表行（状态标记、统计对齐）、差异头部与“打开文件”、全部抵消与不在范围的状态。
- 历史卡片：头部、⋯ 菜单、列表与树行、空状态。
- 改动卡片：图标块、两行文字、按钮、行悬停、页脚。
- 分隔线、拖动反馈、焦点环、浮窗阴影、过渡动画与明暗对比。

每项结论记录为“保持”或“重设计 + 原因”，写入本文“审查结果”。重设计在本方案范围内自行决定；若需要改变 README 或本文已定的行为，先停下汇报。

## 审查结果

基线截图保存在 `/tmp/gupi-panel-polish-shots/before-{light,dark}-{wide,narrow}.png`（隔离 gallery，静态四文件记录）。

| 审查项 | 决定与原因 |
| --- | --- |
| 标题栏分区、对齐与拖动 | 重设计：工作区标签当前在第二行，与标题栏分离；改为同宽右段，按钮使用 chrome 控件尺寸，空白保持原生拖动。 |
| 标签形状、状态与交互 | 重设计：当前直角标签、常驻关闭、无拖动/中键；采用 Base Tab 的语义与应用组合，圆角顶部、受控排序、插入提示、焦点与滚动。 |
| 新标签页与最近 | 重设计：当前固定 Files 没有启动入口；工具网格与有界最近列表作为明确的下一步，禁用变更附原因。 |
| 文件树 | 保持：现有 Tree 负责层级、键盘与选中，打开路径标记与空/加载/错误状态保持；不改变连续浏览。 |
| 源码头部 | 保持：文件、路径、只读状态与操作已在一个工具栏，维持查找和返回焦点契约。 |
| 改动列表 | 重设计：路径、状态和统计挤在同一文字层级；增加统一图标槽、弱化目录、固定尾部统计，保留文字状态。 |
| 差异头部 | 重设计：工作区头部与差异组件重复完整路径；收敛为一层文件身份和操作，保持差异内容与只读语义。 |
| 净零与不在范围 | 重设计：当前只有贴边文字；使用无卡片的居中空状态，明确当前原因，不虚构操作。 |
| 历史卡片、菜单与行 | 保持：内缩卡片、单一菜单与虚拟列表/树的层级、状态和 Escape 已统一。 |
| 回复改动卡片 | 保持：图标块、摘要、主操作和文件行已经形成清晰层级，临时窗口不变。 |
| 边界、焦点、浮窗与明暗 | 重设计工作区表面：去掉重复框线；保留单一外边界和内部导航分隔，浮窗阴影表达覆盖层。焦点使用主题 ring，滚动区预留环空间；不新增大幅布局动画。 |

第二轮复查（按完成后的截图）：

| 审查项 | 决定与原因 |
| --- | --- |
| 窄窗口工作区浮窗 | 重设计：浮窗左侧保留的会话条只露出被截断的文字，像排版错误；工作区浮窗下加主题 overlay 遮罩，遮罩吃掉点击并关闭浮窗。历史浮窗是挂在对话旁的小卡片，不加遮罩。 |
| 导航开关位置 | 重设计：开关放在标题栏右段时，与最大化、工作区开关并排成三个相似的面板图标；改由当前标签内容的头部提供：文件标签在源码工具栏（`FolderTree`），改动标签在差异头部（`List`），提示分别为“显示或隐藏文件树 / 改动列表”。标题栏右段只保留标签、`+`、全部标签、最大化和工作区开关。 |
| 改动标签头部 | 重设计：单文件视图仍带差异组件的折叠箭头；隐藏组件文件头，由工作区统一渲染一层头部：弱化目录 + 文件名、写入/错误标记、彩色净统计、“打开文件”和导航开关。改动列表的统计改用同一彩色样式。 |
| 标签栏样式 | 重设计：第一版是灰底条上贴底的上圆角标签（浏览器式），与白色标题栏和居中的标题、按钮不在一条基线上。改为与标题栏同底色、垂直居中的四角圆角标签，高度与标题栏控件一致；选中填浅色底，未选中透明、悬停浅填充；关闭按钮常驻占位只切换可见度，标题不跳动；停靠时工作区段补齐标题栏下边线，浮窗内标签栏自带下边线。 |
| 新标签页 | 重设计：大标题与标签名重复、工具是两块无信息的大空卡片；去掉标题，分组标题改为小号弱化文字，工具改为两列紧凑行（图标、名称、快捷键），变更不可用时以提示和下方说明给出原因；最近行使用图标块与两行文字，页面左对齐。 |

实现选择：最近最多 8 项；每次按 + 新建一个启动器标签；选择工具替换该启动器，若工具已经打开则关闭当前启动器并激活已有标签。最近条目以文件路径或稳定工具调用身份标识；无法在当前范围恢复的改动条目禁用并解释，不发起模型请求。
