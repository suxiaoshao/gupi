## 源码事实：当前外壳

- 设置由 `gpui_kit::component::setting::Settings` 组装（`src/features/settings/layout.rs:412` `Settings::new("gupi-settings")`），侧栏 9 个平级页面：通用、外观、通知、Pi、键盘快捷键、插件、Skills、模板（Prompts）、关于。所有页 `.resettable(false)`，统一 `GroupBoxVariant::Normal`。
- `Settings` 0.7.1 公开 API 只有 `page/pages/sidebar_width/sidebar_size_range/with_group_variant/sidebar_style/default_selected_index/header_style`；`SettingPage` 只有 `title/title_suffix/icon/description/default_open/resettable/group(s)/header_style`。**没有侧栏分区标题 API**。
- 搜索按 SettingItem 的标题、说明和 keywords 子串匹配；自定义渲染项依赖 keywords（见 [issue-231](../issue-231/README.md)）。
- 大量项用 `SettingItem::render` 自绘整块内容，未分组标题的 `SettingGroup` 较多，层级主要靠分组框而非标题与间距。
- 列表类页面（插件/Skills/模板）每行有 3–5 个仅图标的 ghost 按钮（位置、编辑、删除、更新、移除），外加启停 Switch。

## Zed 参考：适合与不适合

| Zed 源码 | 观察到的做法 | 对 Gupi |
| --- | --- | --- |
| `crates/settings_ui/src/page_data.rs:535` 起 `appearance_page` | 主题模式与“浅色主题 / 深色主题”是带说明的独立字段，主题用选择器（`components/theme_picker.rs`）而非大网格 | 可借鉴字段说明写法：明确“系统模式下浅色时用哪个主题”。是否放弃预览网格见 S-4 |
| `crates/settings_ui/src/settings_ui.rs:1085` `SettingsPageItem::SectionHeader` | 页内用分区标题组织大量字段 | 适合：每个 SettingGroup 都给标题 |
| `crates/extensions_ui/src/extensions_ui.rs` | 扩展是工作区中的独立页面（Item），不在设置窗口内 | 作为 P-1 备选，见 [packages.md](packages.md) |

### S-1 改造范围

- **采用**：每页都至少完成共享版式（分组标题、间距、行操作模式），并做下表列出的页面专属改动。理由：用户反馈的是“许多页面”，只改快捷键与包无法回应；改动多为呈现，不改设置语义。代价：评审与运行时验证面覆盖全部 9 页。
- **备选 A**：只做共享版式，专属改动仅限快捷键与包。代价：通用、通知、Pi、关于的结构问题保留。
- **备选 B**：参考 Zed 全面替换控件（选择器代替网格等）。代价：范围最大，改变用户已熟悉的外观选择方式。

### S-2 导航分组

- **采用**：平级顺序改为 通用 · 外观 · 通知 · 键盘快捷键 · Pi · 包 · Skills · 模板 · 关于（把偏好放前，Pi 及其资源连续排列）。理由：`Settings` 0.7.1 无分区 API，项目约定不为一次改动擅自升级共享依赖。代价：偏好与资源管理仍只靠顺序区分。
- **备选 A**：向上游 `suxiaoshao/gpui` 增加侧栏分区能力后分两段。代价：跨仓库改动与 revision 升级，需要用户授权。
- **备选 B**：包/Skills/模板移到独立窗口或主窗口页面（类似 Zed 扩展页）。代价：改变入口和窗口结构，影响面最大。

### S-3 命名

- **采用**“包”：与 Pi 文档“package”一致，市场浏览的对象也是包，包内再含扩展/Skill/模板/主题。代价：老用户需要重新识别入口；需同步 9 种语言。
- 备选“插件”：保持熟悉，但与 Pi 术语错位；“扩展包”：中文更直观，但与“扩展（extension）”易混。

### S-4 外观页

- 源码事实：颜色模式为三选一 Radio；应用图标与浅色、深色主题均为卡片网格，两组网格始终全部渲染（`layout.rs` appearance 段）。
- **采用**保留卡片（预览价值高），缩小卡片并在“跟随系统”时标出当前实际使用的主题；颜色模式改为靠近标签的分段控件。代价：页面仍偏长。
- **备选 A**（Zed 式选择器）：页面短、层级清晰；代价：失去直接预览，需要另做选择器内预览。

## 共享版式（已确认，S-1）

- 每个 SettingGroup 都有标题；不嵌套分组框；用字号、字重和间距建立层级。
- 偏好行：标签 + 说明在左，控件在右；说明紧邻所描述的字段。
- 列表页统一工具栏：搜索 · 筛选 · 一个普通（非 primary）主操作按钮。
- 行操作遵循 S-8；破坏性操作在菜单中与其他项分隔，并保留现有确认对话框。
- 保持现有搜索 keywords 覆盖；新增分区标题需同步纳入相关项的 keywords。
