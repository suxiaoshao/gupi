# Git 与 Diff 阅读器

状态：Git 双文本比较简化已实现，验证范围与限制见文末。对应 [Gupi #86](https://github.com/suxiaoshao/gupi/issues/86)。

## 决策

扩展现有右侧工作区 Changes 视图，复用文件导航与 GPUI Kit `Diff`，让用户读清修改、定位文件并在外部编辑器继续工作。增加实际 Git 工作区来源，与 Pi 每轮工具记录共用阅读器，始终标明来源。

全程只读。不提供 stage/unstage/revert、commit/push/PR、评论、worktree 管理或终端；不经 Pi `bash` 获取 Git 数据，不写 Pi 会话。遵循 [职责边界](../../gui-boundary.md) 与 GPUI Kit Coding/Design Guides，不另写 diff 绘制器；临时适配直接依赖 Kit 已使用的 `similar = "2.7.0"`。

### 布局与来源

右侧工作区内是“分组文件导航 + 差异正文”，用一条细分隔线分区，不套卡片。导航头和正文头同高、同基线，工具栏不换行堆成多层。仓库由当前会话 cwd 决定；分支沿用窗口标题栏，不在正文重复。

```text
┌ Git ─────────────────────────────────────────────────────────┐
│ 文件  +18 −6       ↻ ⋯ │ ▾ src/main.rs · 未暂存 ↑ ↓ ↗ ≡ ⋯ │
│ 搜索文件…              ├─────────────────────────────────────┤
│ ▾ 已暂存  1            │ index → 工作树                        │
│   M main.rs  src  +5 −2 │   18 │ 原文                           │
│ ▾ 未暂存  3            │ − 19 │ 旧内容                         │
│   M main.rs  src  +8 −4 │ + 19 │ 新内容                         │
│   D old.rs   src  −…   │       … 展开上下文 …                  │
│   U notes.md     +5    │                                      │
└────────────────────────┴─────────────────────────────────────┘
```

- 固定提供“已暂存”和“未暂存”两个组；未跟踪文件放在未暂存组，用 `U`／“未跟踪”可访问名称明确区分，不另设第三个切换按钮。冲突存在时单独置顶“冲突”，只显示状态，不提供解决操作。空组保留组头及真实零计数，仓库全空时显示一个空态。
- 已暂存比较 HEAD→index，未暂存比较 index→工作树，未跟踪比较空→工作树；未跟踪不冒充 index 中已有文件。无提交仓库沿用读取层空基线语义。组内文件身份仍为 `(来源, 原始路径)`；同一路径两处出现时读取不同版本，不合并统计或正文。
- 文件行保持单行、统一紧凑高度：状态标记、文件名、弱化父目录、右对齐增删数。完整路径放 tooltip 和正文头；长路径省略，不增高行。状态同时有图形或字母与可访问名称，不只靠颜色。不可用统计留空，不伪造零。 Git 文件列表头部按 Zed 只显示非零的已知增删数之和：全未知或已知总计为零均隐藏；混合时显示已知文本小计，不标记不完整。Pi 改动卡片统计不变。
- 搜索跨组过滤；上一/下一文件在当前可见结果中移动，边界禁用。保留已有 palette/token 等其他界面不动。保留下述列表／树视图，不增加排序或分组设置。
- **与 Zed 的明确差别**：Zed Project Diff 是多文件 multibuffer；本次仍按需阅读一个选中文件，复用现有 navigator 和 Kit Diff，避免把重设计扩大成虚拟编辑器工程。借用其分区、密度、文件头和稳定更新方式，不声称已实现连续多文件阅读。
- 窄区沿用现有导航折叠/返回机制，正文保留“文件列表”入口；正文宽度不足时统一视图，变宽恢复并排偏好。窄宽原因放阅读选项（sliders）按钮的 tooltip 和可访问名称，不放进菜单项文案或常驻工具栏。

### 正文头与操作

正文只有一个固定高度文件头：左侧本文件折叠箭头、路径与来源；右侧依次为上一/下一文件、外部打开、阅读选项（sliders）、文件操作（⋯）、文件列表开关。每个图标按钮均有 tooltip 和可访问名称。 本文件折叠按钮只在实际显示的已加载正文包含 DiffBlock 时启用；Git 状态正文（含空文件、纯权限及不可读状态）与 Pi 超限正文禁用，不因保留的折叠意图误报“展开”。更新中或失败后仍显示旧 DiffBlock 时，继续按旧正文提供真实折叠。比较方向用 Diff 左右版本标签（统一模式用紧凑标签），不再增加重复页面标题、说明段。Git 冲突条目的文件头只标明“冲突”，不伪装成 staged／unstaged 方向比较，路径 tooltip 同样不显示来源及方向。打开动作指向当前路径，不预先检查磁盘存在性；Pi 按当前范围内所选路径启用，Git 按来源语义启用（删除、特殊对象、无效 Unicode 路径仍禁用）。点击后由系统实际打开；失败以本地化通知明确提示，不缓存文件是否存在。

阅读选项菜单使用 Kit 原生 label/separator/check：在“视图”下列出互斥的“统一／并排”，只勾选实际生效项；在“显示”下列出“字内差异／自动换行／全部未变更行”。窄宽时并排项为普通禁用项，保留偏好并在变宽后恢复；Kit 0.8 不提供禁用菜单项 tooltip，因此原因明确属于 sliders 触发按钮的 tooltip 与可访问名称，不宣称菜单项本身有原因提示。Git 文件操作菜单提供“复制文件路径／复制文件全文”，分隔后是“在外部编辑器打开”；Git 不提供 patch 导出，Pi Changes 保留“复制 patch”；不可用项可见但禁用。选区复制沿用 Kit。字内差异默认开启。文件头保留本文件折叠入口；删除单文件阅读界面里的“折叠全部/展开全部”和跨未加载文件的隐式折叠意图。上下文 disclosure 仍就地可见，与文件折叠分开。

二进制、删除、空文本、冲突、特殊文件和超限各显示真实内容状态；错误在当前正文区域提供本地化的读取失败文案及重试，技术细节记入日志，不用空 patch 冒充成功。成功发现“不是仓库”清除旧快照错误并显示对应状态。Pi 记录缺少全文时禁用全文动作，不拿当前磁盘补历史。外部打开和复制保留既有只读边界。

固定文件头不插入刷新占位行；相同成员/统计不重建导航投影。正文每次成功刷新重读，相同文本保留阅读状态。

## 工作区标签拖拽

标签始终留在栏内，维持抓取时尺寸，实时换位；不采用拖拽预览加松手插入的交互。`Tabs` 继续拥有领域 order/active，单个 `strip::Interaction` 保存按下抓取偏移、手势、槽位测量与表现状态，不另建 Entity，不持久化排序或回滚已完成的换位。

- 排序只看未平移的外层 slot wrapper 与冻结宽度／间距：右移的右前沿越过下一项中线、左移的左前沿越过前一项中线后换位，带 1px 小滞回；同次事件可以跨多项。动画位置不参与排序。
- 按下时记住当前可见位置的抓取偏移，`on_drag` 启动时立即消费当前移动坐标。窗口 Capture 处理后续移动与最终松手坐标，统一幂等结束，独立于子元素 Bubble 和 pane resize 路由。Escape、失活、会话切换及标签集合变化同样结束手势，保留实时顺序。
- 普通滚动或可见栏几何变化会安全结束当前手势，不复用旧快照；支持从非零滚动位置开始。可见栏宽小于标签宽时不继续拖动，不扩大栏的夹紧范围。活动标签矩形夹紧在可见栏中，松手后向名义槽位回位。
- 邻居与回位表现使用 Kit `spring` 和主题 `spring_move`，key 包含会话、标签和每次手势的唯一身份；重拖从独立记录的可见姿态开始，名义几何不受上一次 spring 影响。settle 后释放冻结表现状态。
- 浮起层显式继承祖先与可见栏交集的 mask，同时用于 prepaint 命中及 paint，不能只依赖 deferred 的绘制裁剪；邻居、标题栏空白区和其它控件不应被不可见标签截获。

### 投影、折叠与选择

- 复用当前虚拟 `ListState`，投影为 `Group / Directory / File` 三类固定高度行；不再引入第二套 Kit `TreeState`。只从已有 Entry 的原始路径组件构造目录，不扫描磁盘；已删除文件仍能生成其目录。目录身份为 `(组, 原始相对目录)`，叶子沿用 `(来源, 原始路径)`；显示文本不参与身份。各级目录先、文件后，分别按路径稳定排序，不合并单子目录链。
- 每个 Git 标签保留关闭目录集合，默认全部展开；普通刷新、列表／树切换保留该集合，已消失目录剪枝，仓库或 cwd 改变清空。目录与分组只控制投影，不拥有正文。点击或 Enter 切换展开；上下键走可见行，左右键展开／收起或到父节点。目录与分组提供名称、计数、展开状态，文件保留状态名称与既有可访问角色。
- 目录计数为当前搜索匹配的全部后代叶子条目数，不受折叠影响，不跨来源去重。常驻只显示计数；增删合计放 tooltip，且仅在全部后代统计可用时作为完整合计展示，混合未知时说明统计不完整，不把缺失值当零。叶子继续显示自己的增删数。
- 正文选择独立于导航焦点：折叠当前文件祖先不清正文、不取消读取。前后文件只走当前搜索及展开后可见叶子，跳过目录／分组且不循环；当前正文因折叠隐藏时，以完整树顺序中的位置找最近可见前后叶子，不因可见索引缺失就把两按钮都禁用。
- 切换列表／树保留来源限定的文件身份、正文实体、滚动与选区；主动进入树视图时为当前文件展开祖先一次，显示其位置。后台刷新不主动展开或滚动，不变清单不重建投影。

### 搜索与持久化

搜索保持现有完整路径／旧路径匹配：先过滤文件，再构造匹配文件的祖先树。搜索期间临时展开匹配祖先，不修改普通折叠集合；清空搜索恢复原集合。选中资格从匹配的源条目计算，不能从折叠后的可见行反推。搜索、折叠和视图切换均不触发额外 Git 或文件系统读取。

只将视图枚举持久化到现有 `state.toml` 的 `LayoutState`，默认 List；启动沿用同步加载，在首次显示前读取真实偏好。全局 LayoutState 是视图偏好的唯一来源，各窗口只持有投影及目录折叠状态，不另存默认值后异步覆盖。更新现有 capture/save 路径保留该字段，沿用既有保存机制；不新增配置文件、独立写任务，也不持久化过滤词、折叠集合或选择。

## 读取与正文所有权

Git/diff 以 Zed 为功能上限，agent 以 Pi 为上限。参考产品没有的额外机制先报告，由用户决定，不自行扩展。

### 资源层

- 当前会话 cwd 决定仓库。单次 porcelain v2 status（no-renames）拆成 staged／unstaged／untracked 成员；numstat 只补列表统计，失败不删除成员、不阻塞正文。
- 正文返回有界的两侧原始文本：staged 为捕获的 HEAD/index OID，unstaged 为 index/当前工作文件，untracked 为不存在/当前工作文件，删除为原侧/不存在。不存在为 None，真实空文件为 Some("")，读取失败不能当成空文件。
- 不再用 Git diff 生成正文，不返回导出 patch，不查询 core.fileMode 或合成 mode 元数据；删除读正文前后的 status／numstat 校验。不保证整个仓库原子快照，下一次成功刷新重读当前正文。
- 非 UTF-8 路径保留原字节身份和列表条目，读取前明确拒绝，相关复制和打开禁用。symlink 显示链接文本，不读目标；特殊对象不当普通文件打开。已删除路径被同名目录替代时新侧仍不存在，子文件是独立 untracked 条目。
- 属性 binary／-diff 可使列表统计未知，正文仅按实际 UTF-8/NUL 判定，不运行 external diff 或 textconv。

### UI 当前正文

- 每个 Git 标签只保留当前正文和一个在途请求，不保留八文件缓存。每次 status 成功重读选择，即使成员／统计没变；不启动重复任务。status 失败保留旧清单与正文。
- 会话、仓库/cwd、来源/路径、选择和请求代次决定结果归属，旧结果不能覆盖新选择。切文件不显示前项正文；同文件刷新保留旧正文，准备好再替换，失败可重试。
- 后台先比较同文件规范化文本，未变时跳过 similar、序列化和解析，只更新原始全文，保留 DiffState、滚动和选择。不同文件不复用选择状态。文本变化不保证跨版本恢复任意视口，不自动跳到旧选区。
- 状态为文本 diff、没有文本改动、无法预览（binary／超限／特殊对象／非法路径等原因）、读取失败加重试。冲突只标注。空新增/删除及纯权限变化没有文本改动，不显示 mode 说明。
- 全文复制使用显示快照的原始可用侧，删除复制原侧。只有实际显示的 DiffBlock 能折叠。Git 没有 patch 复制／导出。
- sync_worktree 负责可见 Git 标签的轮询启停；返回对话、切标签/会话、窗口与侧栏几何变化在事件侧同步，不从 render 启动任务。

### 本地文本适配

git_changes/text.rs 在后台用 similar 2.7.0 比较两段文本，仅为显示统一 CRLF/LF。使用完整上下文和一秒计算预算，生成标准 unified diff 后交给 Kit DiffFile::parse。真实路径不拼入 patch 语法，采用固定安全内部路径并显式设置实际高亮语言；真实路径由外层标题持有。内部差异文本不可导出。

继续复用 Kit 的统一／并排、字内差异、换行、上下文、选区和折叠。未来 Kit 有公开两段文本入口时可替换临时适配，本轮不扩展上游接口。

Pi Changes 的 EditedFiles、ToolIndex、in-scope、净改动、逐操作回退及 patch 复制不变，不从磁盘补历史。两来源只共享展示、布局、选区和导航，不伪造 Pi 操作。

## 限量与验证

- Git 子进程最多 5 秒，stdout 2 MiB、stderr 64 KiB；清单最多 5,000 项，超限不把截断结果当完整清单。
- 单侧文本最多 1 MiB、50,000 行、单行 16 KiB；二进制和超限文件留在列表。Pi 限量及每页三项回退不变。
- 回归覆盖来源、缺失与空文件、读取错误、统计失败不阻塞好文件、单 status、非 UTF-8/特殊对象/链接边界、同文本保留实体和滚动、切文件隔离，以及 Pi patch 不变。
- 夹具用自动清理的 tempfile；GPUI 测试不启动真实 Git。门禁为 resources/UI/root 的 fmt、全目标 Clippy（-D warnings）与测试。
- 本轮原生只看 Git 普通修改、未跟踪、删除、二进制、超限各一个。工具报错立即报告，不以替代路径冒充验收。
