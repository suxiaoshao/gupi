# 会话与源码工作区

状态：已实现。本文保留文件浏览、只读预览与状态所有权契约；主窗口的标签、历史面板、宽度分配、浮窗和命令规则见 [主窗口工作区、历史面板与标题栏](../workspace-layout/README.md)。

## 布局与连续浏览

文件树和源码预览位于同一工作区的固定“文件”标签；主内容在左、导航在右。每个对话只有一个源码槽，新文件替换旧文件；同文件保留阅读位置、换行与查找，重读需显式操作。没有文件时只有树。工作区空间不足时整体浮动，打开文件不关闭文件树或浮窗；导航只由用户收起。历史在会话列内独立布局，不再与文件树共用页签。

会话输入框始终属于会话列。会话侧栏的显隐由用户控制，不因打开文件自动关闭。不新增编辑、保存、多文件源码标签、Git 操作或目录监听。

## 视觉层次

导航使用主题 sidebar 表面，源码使用内容 background；停靠边界仅用细线，浮窗使用覆盖层表面与阴影。文件工具栏显示项目名、刷新和更多菜单；完整项目路径放入提示及“复制路径”。源码标题显示文件名、弱化目录、只读标记，以及重读、换行、更多与关闭；换行启用状态持续可见，更多菜单提供复制路径和在文件树定位。

树行总高约 1.75rem、每级缩进 1rem；箭头和图标有固定槽位。选择行使用组件选中填充和焦点状态；当前打开文件另有中等字重及尾部标记。目录加载与失败沿用列表反馈，空目录不添加子提示行。源码加载、不支持及超限反馈放在正文内；长行降级、重读失败保留快照采用行内说明。

## 打开、焦点与键盘

- 单击文件打开快照并保留树焦点，便于连续浏览；上下箭头只移动选择。目录展开/收起语义不变。
- Enter 打开文件并立即聚焦源码容器；只有读取请求仍最新且容器仍有焦点时，异步结果才进入 Editor。加载与错误容器也保留焦点路径。
- Editor 内 Escape 先关闭查找；随后关闭所属浮窗，或从停靠源码返回可见文件树的打开行（父目录折叠则返回最近可见父目录），树隐藏则返回输入框。浮窗关闭按工作区文档恢复按钮焦点，不触发停止回复。
- 普通与扩展多行输入框查找草稿，源码使用 Editor 内置查找，会话消息区域拥有局部查找；导航、加载与错误区域不转接查找。显式“查找会话”关闭浮窗并打开会话查找。
- 关闭文件通过 × 或命令面板，释放正文及读取任务；工作区可见性、浮窗与固定偏好保持。只有被移除内容拥有焦点时才转移到可见导航或输入框。
- 命令面板保留“项目文件”“关闭文件”“聚焦源码”；移除旧单正文槽的“显示会话”。不新增全局快捷键或提及文件功能。

## 状态所有权与本地偏好

HomeView 组合会话、源码及导航可见性/布局；每个 SessionView 独立持有文件导航、源码 Entity、事件订阅及工作区标签状态。文件导航 Entity 的根目录固定为该对话 cwd，拥有目录缓存、展开、选择、滚动与目录任务；源码 retained Entity 拥有当前路径、只读 Editor、快照与读取任务。正文挂载在工作区，与导航显隐独立，移除文件正文 Dialog 生命周期。

切换对话使用各自保留的文件树与源码实例，即使 cwd 相同也不共享。新对话从未展开、未选择且位于顶部的文件树开始；切回已有对话保留展开、选择、滚动、源码快照与当前标签。不在切换时重置根目录、同步缓存或刷新文件树。隐藏对话的既有读取任务仍只更新其所属实例，事件订阅按对话归属处理。关闭文件、移除所属对话或关闭窗口时释放相应源码；移除对话同时释放文件树与订阅。保留视图不改变 Pi 内容，也不持久化到磁盘；文件树定位复用按需子目录读取。

分栏偏好由 `gupi-settings` 拥有，单独保存会话/源码比例，默认 0.4，只接受有限且在 `(0, 1)` 内的值。该比例独立保存，不增加旧版本降级兼容逻辑。缺失、无法读取或无效的新偏好使用默认值，不阻止主窗口布局加载。临时窗口没有此分栏，不读取或写入该偏好。

松开鼠标或按 Escape 都结束拖拽，保留并保存当前尺寸或比例；未变化时不写入。窗口缩放、面板切换等非主动结束会中断拖拽，不保存，并在当前帧恢复拖拽前的原始源码比例（包括未设置状态）。比例只在用户主动结束拖拽时保存；窗口缩放、自动夹取、导航临时收窄及模式切换不写回用户偏好。窗口位置和尺寸继续用平台坐标；侧栏使用 `sidebar_width_rem` / `navigator_width_rem`，只验证有限正数。旧像素字段不迁移，旧布局文件读取失败后使用默认值，窗口位置和侧栏宽度重置一次，不影响应用启动。默认 14rem / 20rem 在 16px 字号下为 224px / 320px。

符号链接跟随目标，与 Pi 对齐；目录链接可展开，文件链接只读预览，目标可在 cwd 外。显示、身份、定位与语言识别仍使用链接的原始路径；链接图标、目标提示和不可用状态单独保留。读取不是 cwd 沙箱，循环链接仅逐层按需展开。文件读取仍限 1MiB、20,000 行、严格 UTF-8/BOM 和普通文件；单行超过 16KiB 使用纯文本。现有 tree-sitter 及其高亮限制保持，由原设计文档记录。
