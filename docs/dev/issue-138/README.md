# #138 自有设置页组合

## 范围与结构

设置页由 Gupi 自有容器组合 GPUI Kit 公开组件，覆盖 Gupi 和 Pi 两个域的 15 页。页面顺序、文件格式、普通偏好的即时保存和 Pi 页的显式保存保持一致；Pi 字段提供直接恢复默认/使用全局值，页面放弃统一处理撤销。设置页不提供 pin（设为全局值/设为项目值）或字段级撤销入口。

正文居中限宽，普通偏好约 `52 rem`，编辑列表与详情约 `59 rem`。普通行左侧为标题与灰色说明，右侧为自然宽度控件；内容不足时上下堆叠。页头、工具栏、表格与组容器共用各页的左右边界。标题栏保留 Gupi/Pi 分段选择；自有侧栏包含搜索和页面项，支持调整宽度。

`SettingsView` 持有导航、查询、滚动与 `Entity<ResizableState>`；分栏使用 `h_resizable` / `resizable_panel`，侧栏使用保留的 `InputState` 与 `SidebarMenuItem.active`。切页、切域和搜索不重建这些状态。正文为一个主纵向滚动者，侧栏溢出独立滚动；独立编辑器与包详情保留自身滚动职责。滚动条使用 Kit 默认覆盖式行为和系统偏好。

## 行、分组与直接操作

普通 `SettingsRow` 只组合公开 `h_flex/v_flex`：左侧 `flex_1 + min_w_0` 承载标题和完整说明，右侧放 Kit 控件。它不持有 Form 编辑状态，不复制 Field 或绑定实现。适合 Field 的独立编辑器继续使用 Field。Kit 0.8 Field 的 label/content wrapper 分配不适合普通行的自然宽度控制，因此普通行由公开布局组合。

普通设置行采用浅填充 `GroupBox.fill`，组标题在容器外，组内使用行分隔。图标/主题网格、快捷键/MCP 表格、资源列表、包列表详情、空态、model map、预算网格及路径编辑不加外层组框。供应商摘要、认证行和系统提示词任务行使用浅填充分组。

数字计数、预算和超时 Input 约 `8 rem`；普通文本 Input 约 `15.25 rem`；Shell、路径等长值展开编辑。预算为两列，超时模式和单位完整显示。map 的整字段来源、未保存与恢复动作位于标题旁，允许换行；单项来源和错误贴近对应项。错误使用主题 danger 文本，不只改变边框颜色。

常用操作使用 `Button.icon` 和对象明确的 Tooltip/可访问名称：编辑 Pencil、删除 Trash、恢复 RotateCcw、移动 ArrowUp/Down。文件页的添加工具栏独立靠右；干净文件不显示空提交栏。MCP 检查使用服务器标题旁的 outline Button + RotateCw，保留检查中、取消和禁用语义；补充作用域与重连说明为 muted，真实错误和信任限制保留明确反馈。登录、文件位置、路径复制和跨页管理等低频操作使用菜单。

Pi 页头的作用域 Select 位于标题旁，打开文件和重读为右侧图标按钮；页级草稿栏位于说明下方。系统提示词行的文件名在标题旁，来源与编辑动作靠近对应值，保持完整行内边距。

## 外观：T1 清晰预览

七种应用图标使用现有图片；主题使用真实配置色值和全部内置选项，包括系统强调色动态主题。主题样本约 `6 rem` 高，展示侧栏、正文和强调色。名称在预览下方完整显示、可换行；名称旁 Check 和强调边界表示选中态。

卡片通过公开 `Button.custom(ButtonCustomVariant::new(cx))`、Styled、原有 ThemeGrid 和图片组合。普通/hover/active 背景透明，hover 只加强预览边界，不改变预览配色。没有复述名称的 Tooltip。名称区域使用自然高度，Kit 独立焦点环包住预览及名称，能够与选中态同时显示。Tab 聚焦、Enter/Space 选择，重复点击不取消单选；即时保存失败保留原选项。

## 快捷键

顶部第一行放文字搜索和按键搜索；第二行左侧为“仅已自定义”，右侧为低强调“全部恢复默认…”。按钮按内容宽度，不足时换行。全局快捷键组标题旁放“添加模板任务…”，应用内快捷键域保留应用、会话、工作区与文件、会话文件和临时会话分组。

表头和行共用“命令与说明 / 快捷键与操作”两列；窄内容时上下堆叠并隐藏列头。临时窗口行说明为“显示临时窗口；Gupi 在后台时也可使用。”；模板任务显示实际名称、模板和来源。只有可删除任务在命令前显示 Trash，内置命令从内容左边界开始，没有删除占位列。启用 Switch、编辑 Pencil 和非默认命令恢复图标紧跟绑定区域。

绑定区域为 `[ ⌃⌥F11  X ]` 胶囊。公开 `h_flex`/Styled 定义主题边框、圆角和内边距，`.group(...)` 与保留的非 Tab-stop 焦点范围共同控制显示。录制面是 styled `Button.track_focus` + Kbd；清除是同级 styled ghost Button + X/Tooltip，两者均为正常布局子项。非空绑定为 X 保留固定位置，hover 或区域内聚焦时显示，离开且失焦后隐藏；从 Kbd 移到 X 始终位于同一范围。空绑定不显示 X。

只有外层胶囊表现状态边界：默认浅边框，hover 加深，聚焦或录制时为单圈 ring。内部 key_area 不画边框或圆角，只承载 Kbd 或完整的“按下快捷键，Esc 取消”提示；提示可换行、不截断，录制时隐藏 X。Kit Button 保持原激活方式与无障碍标签；不嵌套按钮、不使用绝对定位覆盖层，不复制 Kit 键盘或命中行为。

X 只清编辑草稿，回焦录制面但不启动录制；确认才保存空绑定，取消恢复原绑定。Tab 可到达 X，Space 可继续录制，Escape 退出录制。冲突检测、定位、默认恢复和页面搜索过滤沿用现有业务逻辑。配置文件集合编辑器的 Add 使用 Kit 0.9 公开的 styled Button::track_focus 与保留焦点句柄，支持 Escape 取消后回 Add、Enter 再打开。

## Pi 来源与恢复

对话、网络、工具与环境的字段和集合组头使用直接来源/恢复展示，没有字段更多菜单。工作值包含本层值时，全局作用域在来源旁显示“恢复默认”，项目作用域显示“使用全局值”；没有本层值时不显示。判定依据为当前 slot 的本层存在性，即使有效值与继承值相等也可移除覆盖。只读字段没有可执行恢复入口，保存中禁用。

恢复将对应字段设为 Unset，清除被替代的编辑草稿，显示有效默认/全局值与未保存状态；按钮随后消失。它进入页草稿，确认保存才删除文件中的本层字段；页面放弃恢复基线与本层存在性。map、路径和范围列表按整字段恢复，每个预算对应独立字段；map 单项仅在有本层覆盖时提供移除。未解析草稿、Unreadable 和外部刷新通过正式 Form/领域接口处理，页面不另存基线或复制合并逻辑。

DefaultTools 使用现有工具 chip、已知工具选择菜单、自定义输入与添加/移除，保留启动工具预览及说明。底层存储顺序、继承和首次修改 materialize 语义保持一致，不排序或按集合重建。路径列表和模型范围使用直接移动/移除图标。模型/MCP 密钥的保留、替换、移除属于独立编辑器的必要语义。

## 搜索、草稿与所有权

搜索仍限当前域，使用已有本地化标题、说明与关键词的包含匹配。渲染与搜索读取同一份页面描述；自定义资源块用其声明关键词参与设置搜索，包名/资源正文等内部过滤仍归原页面。不搜索 API Key、输入值或磁盘全文；不新增搜索历史、结果排序或跨域搜索。

当前页有匹配则保持，无匹配则选择首个匹配页；全域零结果保留完整导航和最近有效选中态，正文用 `EmptyHeader` / `EmptyTitle` / `EmptyDescription` / `EmptyContent(Button)`。它不是加载错误，不用危险色或 Alert。普通切页、过滤与调宽不保存、丢弃、重读配置或重建 Form / InputState / EditorKey。

| 对象 | 所有者与边界 |
| --- | --- |
| 域、页面、查询、分栏与滚动状态 | `SettingsView`，稳定页面身份；Input 只拥有原生编辑状态。 |
| 页面描述与搜索文本 | 设置内固定描述，本地化标题/说明/关键词，不持有第二份设置值。 |
| 普通偏好 | 现有 `gpui_form::Form<AppConfig>` 与 `ConfigController`，沿用即时保存、准备及失败处理。 |
| Pi 配置 | 现有 Form 持有未解析输入、编辑基线和 dirty；`PiConfig` 保留继承、原文件、写盘冲突、业务 key 合并及 Save/Discard 编排。 |
| 认证、配置文件、资源 | 原有 entity、敏感数据规则、操作与生命周期；页面组合不另建业务状态。 |
| 控件交互 | Kit 拥有焦点、IME、选择、菜单/弹层；应用拥有页面布局与业务动作。 |

Kit `component::form::Form/Field` 只是展示布局，不替代共享库 `gpui_form::Form<M>`。Store、Operation、共享 Form 的契约不因美化变更。Pi 的来源/未保存贴值，错误在输入下；信任提示、页级错误/冲突、作用域及 Save/Discard 在页操作区。Save 仍按既有 prepare 处理 invalid，不擅自改变禁用条件；普通偏好不增加全局保存按钮。

## 实现边界与验证

界面使用 Kit 主题 tokens、公开组件及布局能力；共享 Form 管理草稿和绑定，Store/Operation 保留原职责，依赖版本与共享库 revision 保持不变。锁定 Kit 0.8 分栏存在快速拖动 paint 状态的已知限制；应用没有自建拖动实现或绕行。

完整检查在 `nix develop` 中运行：

```sh
cargo fmt --all -- --check
cargo build --workspace --locked
cargo test --workspace --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
```

产品回归覆盖恢复默认进入草稿、放弃和保存、本层存在性、快捷键 hover/清除/确认/回焦/录制/冲突、集合 Add 的 Escape/Enter，以及搜索零结果导航。原生验证使用固定隔离 HOME、Gupi config/data/log、Pi agent/session 和项目目录的 fail-closed 启动器；缺失目录时拒绝启动，系统重启不回退用户默认目录。虚构模型、凭据、资源和本地失败 MCP 命令用于验证，不访问真实 Pi 配置。

原生截图、来源 JSON、哈希清单和各捕获阶段的具体覆盖范围在忽略目录 `build/design/issue-138/native-full/`。截图包含页面布局、主题选择/hover/焦点、快捷键胶囊默认/hover/录制/草稿，以及 Pi 草稿和编辑器。未覆盖真实凭据有效性、成功 MCP/OAuth、公共包安装、其它平台及全部语言/缩放组合；这些截图不证明未执行场景。
