# 主窗口工作区、历史面板与标题栏

状态：稳定双区域外壳与工作区内部响应式布局已实现；源码复审、受影响检查与原生观察范围见文末。本文规定主窗口布局，替换 [会话与源码工作区](../issue-31/ui-redesign.md) 的主窗口窄窗口规则；文件读取、源码预览、Pi 改动合成和临时窗口边界不变。Git 与差异阅读器见 [Git 与改动阅读器](../issue-86/README.md)。

标题栏、标签与面板表现见 [面板界面细节](panel-polish.md)。本文是空间分配、状态与交互恢复的唯一契约。

## 目标与范围

主窗口采用**稳定双区域外壳 + 工作区内部响应式布局**。外层只分配对话与工作区；工作区在给定宽度内安排文件、Git、改动和启动器。切换标签、打开首个文件或收起文件列表不改变外层分界。空间不足时使用原位单区，不使用工作区覆盖层、遮罩或浮窗。

历史仍是对话的导航，保留自己的停靠、浮窗与正文避让规则。本轮不重设计历史，不改 Pi 执行与数据来源，不增加工具、依赖、标签跨重启恢复或临时窗口布局。

## 区域与职责

```text
并排
[会话侧栏] [对话（含历史）] | [工作区：标签栏                 ]
                           | [正文                 | 文件列表]
紧凑工作区（外层分界不变）
[会话侧栏] [对话（含历史）] | [工作区：正文 / 临时文件列表     ]
单区
[会话侧栏] [对话 或 工作区；提供切换入口                       ]
```

会话侧栏由用户控制，不自动收起。工作区只有树或启动器时仍按统一分隔比例占宽，接受它比独立窄树栏占用更多空间，以保持标签切换与外层拖动稳定。主窗口对话正文与输入框共用最大宽度 `Wc=51.25rem` 及历史避让位置；临时窗口保持自身宽度策略。

## 内容与表现

### 工作区标签

文件、Git 与改动使用主从内容；导航可按标签手动收起，空间不足时由内部布局降级：

| 标签 | 类型 | 主内容 | 导航 |
| --- | --- | --- | --- |
| 文件 | 可关闭，同一对话最多一个 | 源码预览；未打开文件时没有主内容 | 项目文件树（未打开文件时始终显示） |
| {回复摘要} | 改动标签，可关闭 | 所选文件的差异 | 这一轮改过的文件 |
| Git | 可关闭 | 工作树 / 暂存区差异 | 来源分组的文件列表或树 |
| 新标签页 | 可关闭 | 启动器占满工作区 | 无 |

- `+` 打开启动器式“新标签页”；工具包括文件、Git 与最近一轮变更，下面列出本对话最近打开的文件和改动（最多 8 项，不跨重启）。选择工具替换当前新标签页；再次打开已有工具激活已有标签。所有标签关闭后保留一个新标签页，工作区不隐藏。Git 与 Pi 各轮改动保持独立来源和标签身份。
- **文件标签**：在树中单击或 Enter 打开文件，只替换预览；双列时沿用 #31 的单击保留树焦点、Enter 聚焦源码，紧凑时按下文临时列表规则转入正文。每个对话仍只有一个源码槽，关闭文件（×）回到只有树。“在文件中显示”切到文件标签、必要时展开树并定位。
- **改动标签**：一轮回复（现有 Run）对应一个标签。点击某轮改动卡片中的文件行，打开或激活该轮标签并选中该文件；在列表中选择其他文件只切换差异；双列时列表保持，紧凑时按临时列表规则转入正文。差异沿用 GPUI Kit 只读差异组件与 #33 的合成结果、“写入”中性显示、错误标记与统计；差异标题提供“打开文件”，切到文件标签打开该文件。回复进行中标签原地更新，结果不变时保留滚动与选择。
- **改动标签的身份与生命周期**：
  - 投影出的 Run ID 会在持久化后变化（`home/messages.rs` 的 Run 投影），标签身份沿用改动卡片的做法，经工具调用 ID 迁移（`home/messages/changes.rs` 的 `sync`）；迁移保持标签顺序、当前标签和所选文件。
  - “可见范围”与“删除”分开判断。`EditedFiles` 只反映当前投影，且会丢掉全部净零的 Run（`edited_files.rs`），不能把“不在 `EditedFiles` 中”当作删除。标签所属工具调用仍在会话记录中、但不在当前分支或历史预览范围内时，标签保留并显示“此回复不在当前范围”，提供关闭；回到范围内恢复内容。只有这些工具调用已不在会话记录中时，标签才自动关闭。
  - 本轮所有文件净变化为零时，标签保留并显示“本轮改动已全部抵消”；所选文件因净零或范围变化消失时，选中下一个文件（末尾时取剩余最后一个），焦点只在原本位于该文件时随之移动。
- **标签标题**：取开启该 Run 的用户消息首行并截断，用户消息为空时显示回复时间；提示中显示完整文字、时间与净 `+a −b`。
- **标签栏**：标准桌面标签，支持栏内实时拖动排序、中键关闭、关闭菜单、横向滚动与全部标签菜单。关闭当前标签激活左侧标签，没有左侧时激活剩余首项；全部关闭回到新标签页。关闭按钮保留操作槽，标题不跳动。当前拖动、稳定槽位与 Capture 收尾契约见 [工作区标签拖拽](../issue-86/README.md#工作区标签拖拽)，布局变化按该契约结束失效手势，不另建一套拖动状态。
- **所有权**：每个对话拥有自己的标签列表、当前标签和各标签状态（导航收起、选择、滚动），切换对话使用各自实例；不持久化到磁盘。

### 历史卡片样式

历史面板在既有分配区域内使用统一 `p_2` 内边距，呈现脱离窗口上、右、下边缘的圆角卡片；不改变停靠阈值、正文位移或面板宽度计算。共用主题 `popover` / `popover_foreground`、细边框和 `radius_lg`，停靠不加阴影，浮窗在同一卡片上增加阴影。圆角约束内部内容，外侧调整宽度的命中区域保持可用；静止时不绘制额外的整高分隔线，悬停与拖动沿用组件反馈。

标题行仅显示“历史”和一个 ⋯ 菜单；菜单依次包含列表/树、内容程度与分支范围，沿用原有选中状态与语义（树模式不显示仅供列表使用的分支范围）。不增加会话摘要或其他内容。

### 改动卡片

主窗口卡片头采用圆角弱化底色的差异图标小块、两行摘要（文件数、净 `+a −b`）及右对齐的描边“查看变更”按钮。按钮打开或激活该 Run 的 Changes 标签并选中第一个文件，使用与文件行相同的显式 ensure-visible 规则。头部下方使用细分隔线，文件行去掉展开箭头，保持悬停反馈、弱化目录、文件名与右对齐统计；底部“再显示 N 个文件 / 收起文件”配方向箭头。没有净统计的 write/回退不虚构数量，保留“写入”“错误”文字标记。

主窗口中，回复下方的改动卡片只做摘要：保留卡片头、文件行（目录弱化、文件名强调、“写入”“错误”标记、净统计）以及“再显示 N 个文件 / 收起文件”。文件行不再原地展开，改为在工作区打开对应改动标签；无障碍名称说明“在工作区中打开”。#33 中原地展开、展开后滚动与焦点保持的规则随之删除，净零文件消失时的焦点规则保留。工具详情对话框中的差异不变。临时窗口没有工作区，同一卡片在临时窗口中保留现有原地展开及其状态，不受本节影响。

## 外层契约：对话与工作区

`home/panes.rs` 与 `panes/geometry.rs` 只接收窗口可用宽、字号、会话侧栏状态、工作区打开意图、分隔比例、最大化与单区前景状态；不接收 `Content::main/navigator`、当前标签类型或导航宽度。输出对话、工作区矩形与呈现模式。工作区内部不能上报动态最小宽度改变外层。

设 `A` 为扣除可见会话侧栏后的宽度，`s` 为外分隔线宽，`C` 为对话宽，`W` 为工作区宽：

```text
Cmin = 24rem
Wmin = 20rem
并排条件：A >= Cmin + s + Wmin
R = A - s
C = clamp(r * R, Cmin, R - Wmin)
W = R - C
r = C / (A - s)
```

`r` 对应 `state.toml` 的 `source_split_ratio`，默认 0.4。分母不扣除内部导航宽度。`Cmin`、`Wmin` 是已确认的起步值，原生验证后再调整；`Wmin` 是面板完成单个任务的下限，不是正文与导航下限之和。

| 条件 | 呈现 |
| --- | --- |
| 工作区关闭 | 对话占满 `A` |
| 工作区打开、可并排、未手动最大化 | 按 `r` 分配两区域 |
| 工作区打开、空间不足 | 当前前景区域占满 `A`，另一区域保留状态 |
| 工作区手动最大化 | 工作区占满 `A` |

并排时外分隔条始终可拖，包括只有树和启动器的标签。外拖动只修改 `r`。当窗口小于单区域下限时，实际区域仍只占真实可用宽，内部截断、滚动或折叠操作，不强撑溢出窗口；本轮不修改系统窗口最小尺寸。

### 打开、单区与最大化

- 标题栏按钮显式打开或关闭工作区，更新现有工作区打开偏好。项目文件、聚焦源码、查看改动、打开 Git 等显式命令确保工作区打开并激活目标；窄窗口进入工作区单区。
- 缩窄时保留用户正在操作的区域；对话输入中不抢焦点，工作区阅读中保留工作区。没有焦点归属时沿用最近前景，初始为对话。后台内容变化不改变前景或打开意图。
- 单区提供“返回对话”和“打开工作区”入口。返回对话只切换前景，不关闭工作区；变宽后按打开意图与保存的比例恢复并排。关闭工作区才清除打开意图。
- 手动最大化与自动单区共用渲染但区分原因。手动最大化变宽后仍保持；按钮或 Escape 退出最大化，空间仍不足时回自动单区。会话切换清除手动最大化；关闭工作区亦清除。关闭全部标签后保留启动器，不因此改变外层布局。
- 最大化和单区不写回比例、导航宽度或自动夹取结果。隐藏区域的标签、编辑器、列表实体与滚动状态不销毁；重新显示时恢复可见焦点目标。

## 内层契约：工作区响应式布局

`home/workspace/layout.rs` 负责共享内部分配。输入仅为外层给定的 `W`、字号、标签内容形态、用户导航显示意图与 `navigator_width_rem`；输出正文与导航矩形及有效呈现。标签可以有不同内部结构，但不影响外层门槛或分隔位置。

- 有正文和导航、用户未收起导航且 `W` 足以容纳内部正文下限、导航下限与分隔线时显示双列。导航按保存值夹取，正文取得剩余宽；内部下限起步为正文 `20rem`、导航 `15rem`，由工作区定义，不参与外层计算。
- 放不下双列时自动只显示正文，保留明显的文件列表入口。点击入口在同一工作区内临时用列表替换正文；选择文件返回正文，返回操作恢复阅读位置。双列中单击文件继续保留列表焦点，Enter 聚焦正文；临时列表被正文替换时焦点进入新正文。
- 自动隐藏是派生结果，不修改标签的 `navigator_hidden`。宽度恢复后自动恢复双列；手动隐藏仍保持隐藏。临界尺寸的恢复可用小幅迟滞，状态归内层，不写入磁盘。
- Files 尚未打开文件时，树就是唯一主体并占满 `W`，不能收起成空白；打开或关闭文件只改变内部布局。启动器占满 `W`，没有虚构导航槽。Git/Changes 有候选文件而未选中时必须提供可用列表，空数据、加载和错误由标签本身呈现。
- `navigator_width_rem` 仅控制双列中的导航首选宽。列表独占工作区时占满 `W`，不修改该偏好。内分隔条只调整导航，不能推动外分隔条或触发外层单区。
- 源码、差异等读者拿到的是实际正文宽度。差异的 split/unified 降级继续由阅读器负责，不反向要求工作区或对话变宽。
- 在给定外层矩形后，同一布局周期计算内层；不先绘制默认尺寸再异步修正外层。切换内容、导航或结果刷新不重建已有阅读实体。

## 历史面板

历史只接收最终对话宽 `C`，沿用既有规则，不参与工作区内部分配。固定且可停靠时显示；固定但不可停靠时保留偏好，按钮可打开临时浮窗；空间恢复后固定历史重新停靠。未固定的浮窗不会因变宽自动固定。显式打开历史可停靠时设为固定，否则打开浮窗；Escape、再次点击或浮窗外点击关闭临时浮窗，不改固定偏好。

设历史首选宽为 `P`，正文与历史间距为 `g`，对话正文下限为 `Bmin`。停靠条件为 `C-P-g >= Bmin`，正文宽与位置为：

```text
B      = min(Wc, C - P - g)
origin = min((C - B) / 2, C - P - g - B)
```

历史不能停靠时，其浮窗贴对话栏右缘，宽度夹取到对话区域。历史卡片与正文连续位移不变。工作区独占时对话及历史暂不可见，恢复后按原偏好重新分配。切工作区标签不改变 `C`，因此不会连带改变历史形态。工作区不再与历史竞争一个共享浮窗槽。

## 状态、拖动与模块归属

| 所有者 | 负责内容 |
| --- | --- |
| `gupi-settings::layout::LayoutState` | 已提交的工作区打开意图、`source_split_ratio`、`navigator_width_rem`、会话侧栏与历史偏好；启动时同步加载 |
| `HomeView` / `home/panes.rs` | 外层实时几何、手动最大化与单区前景、外拖动生命周期；组合内部布局与历史 |
| `home/workspace/layout.rs` | 内部几何、自动降级与恢复；内部拖动边界 |
| 每个对话的工作区与标签 | 标签身份/顺序、选择、滚动、手动导航隐藏、临时列表/正文呈现与焦点 |
| 各内容视图 | 文件树、Git 列表、源码、差异的本地布局、加载与错误 |

两层都从已加载的真实偏好计算首帧。实时拖动值只在内存，释放或 Escape 提交一次；旧移动/释放回调无效。中断时从当前 `LayoutState` 已提交值重新计算，不保存按下快照作为第二份偏好。容器、字号、自动收起或单区切换不写回偏好。不得另存一份与比例竞争的工作区宽度，也不把导航宽迁移为外层比例。临时窗口不读写这些主窗口布局状态。

事件捕获和通用拖动结束机制可以共享，但外分隔与内分隔分别委托所属层计算、提交。内部切换不应无故打断仍有效的外拖动；外几何改变使内拖动前提失效时结束内拖动并重算。标签拖拽继续使用现有几何失效与收尾规则。

### Escape 与焦点

一次 Escape 只处理一层：

1. 菜单、对话框、查找等最上层局部交互先处理；活动分隔拖动按提交契约结束并消费事件。
2. 临时文件列表返回正文；焦点在历史浮窗时关闭该浮窗并回到触发按钮。
3. 工作区手动最大化时退出最大化，不改偏好；仍窄时保留工作区单区。
4. 自动工作区单区返回对话；不关闭工作区、不触发停止回复。
5. 并排正文沿用返回所属树/列表的行为；导航手动隐藏时返回输入框。其余区域保留原有 Escape 行为。

源码或差异不能在父级处理后继续传播并重复退出。关闭面板、标签或被后台移除的内容时，仅当焦点位于其中才转移；不抢正在输入的焦点。

### 标题栏与命令

标题栏与内容使用同一外层矩形。并排时对话段承载会话标题、菜单与历史，工作区段承载标签与面板操作。工作区独占时工作区段占满可用区域并提供返回对话入口；对话独占时保留打开工作区入口。没有额外浮窗标签栏。

历史按钮使用 `RotateCcwClock`；工作区开关按可见性使用 `PanelRightOpen` / `PanelRightClose`，提示与无障碍名称说明当前操作。自动单区中对话可见、工作区打开但暂不可见时，入口是恢复工作区，不把“返回对话”混作关闭工作区。

| 命令 | 行为 |
| --- | --- |
| 标题栏工作区按钮 | 可见时关闭；不可见时打开或恢复当前工作区，必要时进入单区 |
| 返回对话 | 切回对话前景；退出手动最大化，不修改工作区打开偏好 |
| 项目文件 / 聚焦源码 / 查看改动 / Git | 激活目标并确保工作区可见；按目标恢复焦点 |
| 关闭文件 / 内部切标签 | 只改变内部内容，不改变外层几何和打开意图 |
| 历史 / 打开历史 | 保留历史的显式打开、固定或关闭浮窗语义 |
| 查找会话 | 让对话可见，再打开会话查找；不遗失工作区状态 |

### 会话菜单

标题栏 ⋯ 与侧栏会话行共用 `navigation::session_menu`，按组排列，组间用分隔线：

1. 会话信息…、导出会话为 HTML…
