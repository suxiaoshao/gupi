## 源码事实

### 页面结构

- 页面由 `layout.rs` 的 `keyboard` 页组装：顶部无标题操作条（“添加模板任务”+“恢复全部默认”）→ 全局快捷键分组 → 模板任务分组 → 应用 / 会话 / 会话文件 / 临时窗口四组应用命令。
- 应用命令共 41 条（`crates/gupi-settings/src/keybindings.rs` `COMMANDS`），其中 `temporary_session_1..9` 为 9 条独立行。
- 分组由 `keys::Group::of` 决定（`src/features/settings/keys.rs:23`），未列出的命令落入 `_ => Conversation`，例如模型、历史、项目文件、关闭/聚焦源文件都归入“会话”。
- 两条命令使用同一标签 `command-copy-last-answer`：`temporary_copy`（临时窗口）与 `copy_answer`（会话），列表中名称相同。
- 每行是宽 360px 的只读 `InputGroup`，值直接取 `command.value()`，即存储字符串（如 `secondary-shift-p`），未使用 `gpui_component::kbd::Kbd` 格式化（是否在输入框内另行转换为符号：未验证，源码未见）。
- 行内最多 5 个仅图标按钮：清除、录制、恢复默认、确认、取消；数量随状态变化。“清除”只出现在输入非空时。
- 模板任务行：快捷键输入 + 启停 Switch + 编辑 + 删除图标；说明为模板文件名 `/stem`。

### 交互语义（采用方案须保持）

- 录制：点击录制后捕获下一个按键并写入可编辑草稿（`keys.rs:329` `start_recording`）。**Escape 不会被录入**：`keys.rs:345` 跳过 `escape` 并直接结束捕获，因此 Escape 起到取消录制的作用；Backspace 等其他按键会被录入。草稿出现后显示“确认 / 取消”，确认才保存（`confirm` → `save` → `keybindings::validate`）。
- 编辑状态：输入框失焦时停止捕获按键（`keys.rs` `on_focus_out`），但已录入的待保存值仍保留，直到确认或取消；在输入框按 Enter 等同确认。
- 清除（`keys.rs:265` `clear`）只把草稿清空，不弹对话框、不写入配置；之后仍需“确认”才保存为未绑定，“取消”恢复已保存值。单条“恢复默认”仅在已自定义时出现，点击后直接校验并保存默认值（`save(index, None)`），无确认。
- “恢复全部默认”执行 `PreferenceChange::ResetKeybindings`，同时清空应用快捷键覆盖与系统级任务快捷键（`crates/gupi-settings/src/config.rs:153`）。
- 冲突检测（`keybindings.rs` `validate`）：任意两条应用命令不能共享首个按键，与上下文无关；组件快捷键仅在可同时生效的焦点栈中算冲突，但只要候选值等于该命令自身的默认值（条件为 `text != command.default`），就不因组件绑定而拒绝——不限于 Esc（注释只举了 Esc）。冲突以错误文本显示在行下，不自动替换。
- 系统级快捷键（启动临时窗口、模板任务）使用另一条录制路径（`src/features/settings/global_keys.rs` `BindingInput`）：同样跳过 Escape、清除只清空草稿、需“确认”才保存；保存经 `crate::app::shortcuts::validate_registration`，包括 `validate_global`（与所有组件按键首键比较，无默认值豁免）及 `global_hotkey` 注册检查。系统级条目没有“恢复默认”。

### 实际作用范围

临时窗口根上下文为 `"Gupi GupiTemporary GupiApplication"`（`src/features/temporary.rs:495`），因此绑定在 `Gupi` 的命令同样在临时窗口生效；主窗口与临时窗口**不是**互斥范围。

| 绑定上下文（`keybindings.rs` `bindings`） | 命令 | 准确的范围描述 |
| --- | --- | --- |
| 无 | 设置、显示主窗口、退出 | 任意 Gupi 窗口 |
| `GupiApplication` + `Gupi` + `GupiPalette` | 命令面板 | 主窗口（`Gupi`）、临时窗口与启动窗口（`GupiApplication`）、命令面板内；设置窗口是否覆盖：未验证 |
| `Gupi` + `GupiPalette`（`_` 分支） | 多数会话、工作区、文件命令 | 会话视图：主窗口与临时窗口（各命令在临时窗口是否有实际效果：未验证） |
| `Gupi` | 停止 | 标签为“停止生成 / 隐藏临时窗口”：同一按键在不同窗口含义不同 |
| `GupiMessages` | 查找 | 仅消息列表获得焦点时 |
| `GupiTemporary`（+ `> List`） | 临时窗口专属命令 | 临时窗口；“粘贴”为纯 Enter 时，在输入框、命令框、扩展界面内不触发 |
| 系统热键 | 启动临时窗口、模板任务 | Gupi 运行时，其他应用在前台也生效（Linux Wayland 支持：未验证） |

## Zed 参考：适合与不适合

| Zed 源码（`crates/keymap_editor/src/keymap_editor.rs`） | 做法 | 对 Gupi |
| --- | --- | --- |
| `:2149` 表头 `Action / Arguments / Keystrokes / Context / Source` | 表格展示每条绑定，含上下文与来源列 | 适合借鉴“范围”和“已自定义”两列信息；Gupi 无参数、上下文表达式对用户不友好，不直接显示原始 context |
| `:2219` `ui::KeyBinding::from_keystrokes` | 按键以符号渲染 | 适合：对应 GPUI Kit `Kbd` |
| `:191` `SearchMode::KeyStroke { exact_match }` | 可切换为按按键搜索 | 适合，见 K-7 |
| `:217` `FilterState::Conflicts`、`:240` `SourceFilters`（User/Default/Vim） | 冲突筛选、来源筛选 | “仅已自定义”筛选适合；Gupi 校验阻止保存冲突，冲突筛选价值低 |
| `:3077` 起 `KeybindingEditorModal`，`:3207` Cancel / Save；提示“有 N 个绑定使用相同按键”+ View | 在对话框中编辑，显式保存，冲突给出说明与查看入口，不自动替换 | 显式保存与“查看冲突项”适合；是否用对话框见 K-3 |
| `:2345` 起 覆盖提示 tooltip | 被覆盖的行降低不透明度并以 tooltip 解释 | 不采用以 tooltip 作为唯一说明；改为行内可见文字 |
| `:1110` 起 行右键菜单 Create/Edit/Delete/Copy Action | 行级命令在 ContextMenu | 适合，与 `⋯` 菜单并存 |
| Zed 允许多条绑定、上下文自定义、编辑 keymap JSON | 面向高级用户 | 不适合：Gupi 每命令一条绑定、上下文固定 |

### K-1 列表组织

- **采用**：分段为 系统级 · 应用 · 会话 · 工作区与文件 · 临时窗口；每行显示命令名、按键、范围（如“任意 Gupi 窗口”“主窗口与临时窗口”“消息列表聚焦时”“临时窗口”）、“已自定义”标记。理由：用户关心“这个键做什么、在哪里生效”；范围与分组正交，单独成列可避免把重叠范围硬拆为互斥分段。代价：多一列信息，窄窗口需折叠为第二行。
- **备选 A**（按范围分段）：分段即说明范围。代价：重叠范围（会话命令同时在两个窗口生效）难以诚实表达，“停止/隐藏”这类双义命令无处归属。
- **备选 B**（Zed 式表格）：信息完整、可排序。代价：需 DataTable 与列宽管理；对 41 条命令的设置页偏重。

### K-3 录制交互

- **采用**：保持现有语义（录制 → 草稿 → 确认/取消），把仅图标的 ✓/✕ 换成带文字的“保存”“取消”，录制中显示“按下快捷键，Esc 取消”。Escape 继续结束录制而不录入；Backspace 等仍可录入。应用命令与系统级两条录制路径保持一致。代价：比即时保存多一步；Escape 无法通过录制分配（现状如此，Stop 的默认 Esc 不受影响）。
- 草稿生命周期（已确认，K-3）：保留既有交互并明确以下生命周期——失焦只停止捕获，草稿保留并显示“未保存”；切换设置页或关闭窗口时丢弃草稿并恢复已保存值（未验证现有行为）；写入失败时保留草稿并在行内显示错误。草稿不得显示为已保存值。状态归属见 [implementation.md](implementation.md)。
- **备选 A**（Zed 对话框，`keymap_editor.rs:3077`）：编辑空间大，冲突说明可完整展示。代价：每次修改都要打开对话框，焦点在关闭后需回到该行。
- **备选 B**（即时保存）：最快；代价：改变现有语义，误按 Backspace 等即被保存。
- **备选 C**（Escape 可录入）：需另设退出录制的方式（例如只靠“取消”按钮或专门的录制控件），并同时修改两条录制路径。代价：改变现有行为，键盘用户失去 Esc 取消的路径，需单独决策。

### K-5 冲突

- **采用**：录制后若校验失败，在行内显示“⌘K 已被“操作”（临时窗口）使用”与“显示”按钮，聚焦并滚动到占用行；不保存。代价：用户需先去改另一条。
- **备选 A**：提供“替换”（同时清除另一条）。代价：一次操作修改两条绑定，属于新语义，需要用户确认。
