# 选中文本引用到输入框

当前设计采用 **B：输入框外的引用附件区**。选中后自动弹出工具条加入引用；正文继续使用普通 Textarea，所有引用合并为一个“N 条引用”附件标签，每条可附可编辑的评论，发送时才组合成普通文本。本文是改造后的目标契约，不代表附件区已经实现或验收。

## 目标与边界

从对话正文、现有只读源码或差异中选一段，把**当时显示的内容快照**加入当前会话的引用附件，可为每条引用附一段评论，也可在正文中写问题。引用动作不发送消息、不执行工具、不读取磁盘补全。标题明确注明“选中时的内容”，不将快照冒充最新文件。

以 Codex 桌面版 Add to chat / Comment 为能力上限：使用选区浮动工具条、附件呈现、快照语义和每条引用的可编辑评论（对应 Codex 回答批注的 optional comment）；引用原文不可编辑。不做富文本输入框、原文编辑、Codex 的 More details / Ask in side chat / Edit（模型改写文件）、专用 diff 评论编辑器、`:codex-annotation`、出处回跳、批注线程、自动修改文件或 PR 评论同步。不按坐标重新读内容，不监听或检测来源变化；路径、行号和侧别只是来源说明。

Pi 仍只收到现有 `prompt.message` 普通文本及既有图片附件，不增加 RPC 或 Pi 会话元数据。历史使用 Pi 保存的普通用户消息和现有 Markdown 渲染，不重新投影为引用 chip。富文本输入框另行研究，不是本功能的前置条件。

## 入口与公开 API

依据锁定的 `gpui-base` / `gpui-component` **0.8.0**；下列路径相对各 crate 的 `src/`，不是对后续版本的假设。

| 来源 | 可用公开接口 | 取值与限制 |
| --- | --- | --- |
| 对话正文 | `TextViewState::selected_text()`、`selected_source_range()`、`rendered_text()`；`text/state.rs:407–421`。Gupi `home/messages/markdown.rs` 已保留 `Entity<TextViewState>`。 | 取当前这一个 Markdown 正文的选中文本，沿用当前默认 `SelectionFormat::Plain`，不重新解析消息、不用字符串搜索定位重复片段。角色从拥有这段正文的消息取得。`selected_source_range` 只在精确映射存在时可用，本功能不依赖其推算文件行号。 |
| 只读源码 | `EditorState` 是 `InputBaseState<EditorMode>`；公开 `selected_range()`、`selected_text()`、`text()`。见 Base `input/base/state.rs:3344,3996`；组件 `input/editor.rs:109` 的 `context_menu`。 | 对 `home/source.rs::Preview.editor` 的已加载文本取 UTF-8 字节范围和内容；行号按该文本中的逻辑换行计算，一基、末端不包含下一行。保留部分行，不扩成整行。折行显示不改变行号。只读不妨碍选择。 |
| Diff 行号选区 | `DiffState::selected_lines()`、`selected_text(cx)`、`DiffEvent::{SelectionChanged,SelectionEnded}`；`diff/state.rs:79,508,723`。`DiffLineRange` 公开 path、side/start、end_side/end（`diff/document.rs:66–108`）。 | 支持同一文件、同一侧的行号选区；行号为一基闭区间，正文由 Kit 返回，不包含 gutter、`+/-` 或批注。以 Gupi 已加载对象的真实路径和来源作标题，不使用 Git 文本适配器内部的占位文件名。 |

**Diff 的明确限制：**字符拖选可以通过 `selected_text(cx)` 得到文本，但精确源范围/侧别提取位于私有 `diff/selection.rs::selected_source_range`，`DiffState::selection()` 也为 `pub(crate)`；字符选区不能假定同时有可靠 `selected_lines()`。跨旧新侧的行号选区虽然有两个端点，返回正文可能混合两侧且没有符号，不能标成“新侧”或“旧侧”。首版只启用**单侧行号选区**；其他 Diff 选区提示“请从行号选择同一侧的内容”。不按鼠标 X 坐标猜侧别，不匹配文本反推位置，不复制依赖私有实现。若要求所有字符选区都携带精确侧别/行号，需要先有上游公开接口，不能以当前 API 宣称完整支持。

对话首版限一个正文 TextView 内的选区，不将跨消息选择拼为一个虚构角色。源码多光标不组合为连续选区。Diff 的纯文本 fallback、二进制、超限或无法读取状态没有可靠的文件侧别/行号，不提供该入口；仍保留已有复制能力。Pi Changes 和 Git 的正常 DiffBlock 共用入口，出处语义分别来自各自拥有者。

## 入口、捕获与目标绑定

工具条操作名为“引用” / “Quote”；右键菜单与命令面板的备用入口名为“引用到输入框” / “Quote in composer”，备用入口只添加引用、不弹评论输入框。主入口是**选区浮动工具条**；选区右键菜单保留“引用到输入框”作为备用，命令面板保留键盘入口。不加专用快捷键。

### 浮动工具条

```text
            ┌──────────┐
            │ ❝ 引用    │
            └──────────┘
   ……被选中的文字被选中的文字……
```

- **出现：**在对话正文 TextView、只读源码 Editor、Diff（单侧行号选区）中，**鼠标**拖选结束（指针松开）且选区非空时出现；拖选过程中不出现，没有出现延迟或动画。键盘选择（Shift + 方向键）不弹工具条，使用右键菜单或命令面板。
- **定位（简化）：**Kit 0.8 未公开 TextView / Diff 的选区行几何，三种来源统一以**指针松开点**为锚：工具条水平居中于该点，底边位于该点上方 0.5rem；距所在区域可见边界不足 0.5rem 时向内夹紧；上方空间不足时放到该点下方 0.5rem。不追求贴合选区首行；上游若以后公开选区几何，可再改为贴合选区，不属于本版契约。
- **消失：**在工具条外按下指针、选区折叠或变化、来源区域滚动、Escape、窗口失焦、会话切换、来源组件卸载时立即消失；滚动时不跟随，直接隐藏。
- **样式：**容器使用 Kit 弹层背景 `popover`、`border` 1px、`radius_lg`、大阴影；只有一个按钮“引用”（引号图标 + 文字），`ghost`、`xsmall`、`text_sm`。颜色、圆角、间距全部使用主题 token 与 rem。
- **按钮：**“引用”添加一条引用，同时在工具条原位置换成**评论输入框**（同 Codex 的 Add to chat 打开批注编辑器），执行前清除来源选区。评论输入框见下文；关闭输入框即完成引用，不写评论等于只引用。
- **禁用：**Diff 字符选区或跨旧新侧选区时，工具条照常出现但按钮禁用，tooltip 说明“请从行号选择同一侧的内容”。草稿不可编辑、扩展问答占用输入框或 Shell 模式时同样禁用并给出本地化理由。不退出 Shell、不写扩展问答、不新建或切换会话。

### 捕获与绑定

复用 `home/quote.rs` 的捕获、格式化、来源信息和一次性目标 key/binding。工具条显示时即生成快照（捕获发生在任何按钮、菜单或命令面板接管焦点前）；流式更新不改变这次快照。执行时再次核对目标会话和可编辑状态，失效则取消，不能把引用放到另一会话。一次性载荷执行后释放；成功添加的附件转由会话草稿拥有，不建立全局“最近引用”缓存。

添加后显示该会话的输入区域，必要时通过既有入口从工作区单区前景返回对话；工具条“引用”打开评论输入框，关闭后聚焦 Textarea；备用入口直接聚焦 Textarea。均保留 Textarea 的文字、token、光标和选择。不插入占位字符，不改分隔比例，引用标签滚动到可见位置。引用不修改 Textarea，也不强行提交或清除 IME 组合。

## 会话数据与所有权

每个会话的草稿拥有按添加顺序排列的 `QuoteAttachment`。会话切换只显示对应草稿，不转移或重抓引用。每条附件包含：

| 字段 | 契约 |
| --- | --- |
| `id` | 稳定附件身份，用于呈现、删除和提交快照；不使用数组下标或路径作为唯一身份。 |
| 原文快照 | 捕获时的完整已加载选区，保留换行和缩进，不在发送时取最新内容。 |
| 来源标题 | 添加时按当前界面语言形成的完整标题，包含“选中时的内容”；之后切换语言不改这条引用的标题或正文。 |
| 来源类型 | 对话角色、文件、Git 来源组或 Pi 本轮改动，用于格式化与来源展示。 |
| 路径、行号、侧别 | 文件和 Diff 保存已知真实路径及一基范围；Diff 保存旧/新侧与 Git 来源组。对话无文件路径/行号，不伪造。 |
| 语言 | 来源已有的代码语言信息，可空；只用于围栏展示。 |
| 评论 | 可选，用户可随时编辑；空字符串等同无评论。原文快照不可编辑。 |

路径显示优先相对于捕获会话 cwd，不能相对时使用绝对路径；保留足够来源信息以解释路径，不随当前窗口 cwd 改写。路径中的控制字符使用可区分的显示形式。坐标不是读取凭证，来源删除、移动、会话内容刷新或 diff 消失均不使已添加快照失效。

重复添加保留为不同附件，不去重、不合并、不支持排序。附件增删属于草稿变化，纳入既有 revision、保存与发送生命周期；Popover 开关等展示状态由 UI 拥有，不持久化。

## 评论输入框、引用标签与列表弹层

### 评论输入框

```text
   ┌─────────────────────────────────┐
   │ 添加评论（可选）…            ↩  │
   └─────────────────────────────────┘
```

胶囊形单行输入，宽约 18rem（不超过可用宽度），自动增高至最多 4 行；背景 `popover`、`border`、圆角 full、中等阴影；占位“添加评论（可选）…”。Enter 保存，Shift+Enter 换行。**关闭即保存**：Escape、点击外部、失焦或会话切换都会保存当前已写内容并关闭；空内容即无评论。同一组件也用于列表弹层中的评论编辑。

### 引用标签与列表弹层

所有引用合并为输入框附件区的**一个**胶囊标签（同 Codex 的 “N 条注释” pill），与图片附件同一行：

```text
┌──────────────┐
│ 💬 3 条引用 ✕ │
└──────────────┘
```

- 高度与图片附件中的标签一致，`text_sm`；引用图标 + “N 条引用”（Fluent 复数）；右侧 ✕ 清空全部引用，不弹确认。
- 悬停打开的列表，指针离开标签与列表约 100ms 后关闭；点击或键盘 Enter/Space 打开的列表保持打开，直到点击外部、Escape 或会话切换。正在编辑评论时任何方式都不自动关闭（关闭时按“关闭即保存”处理）。

```text
┌──────────────────────────────────────────────┐
│ 1.  所选文本：                         ✎  🗑  │
│     4 千卡                                    │
│     用户评论：                                │
│     你好                                      │
│ ─────────────────────────────────────────── │
│ 2.  app.rs · 12–14 行：                ✎  🗑  │
│     if cancelled { return; }                  │
└──────────────────────────────────────────────┘
```

- 每条：序号；标签行 `text_xs`、`muted_foreground`——对话为“所选文本：”，文件为“app.rs · 12–14 行：”，Diff 追加“旧侧/新侧”；原文最多 3 行（文件/Diff 等宽）；有评论时追加“用户评论：”与评论（`text_sm`、foreground）。完整路径与来源在标签行 tooltip 可读。
- 右侧两个图标按钮（`ghost`、`xsmall`、带可访问名称）：✎ 编辑——将该条评论区换成上述胶囊评论输入框，Enter 保存、关闭即保存；🗑 删除该条。
- 条目间细分隔线；弹层宽 20rem（不超过可用宽度），条目多时列表内滚动。原文只读、可选择复制。删除最后一条后标签与弹层一起消失，焦点回到 Textarea。删除不进入正文撤销栈。
- 正文输入、发送、会话切换不留下指向旧附件的浮层；未保存的评论按“关闭即保存”处理。

## 编辑评论时的来源高亮

**已确认采用方案 a（类 Codex）：只高亮当前正在编辑评论的那条引用，编辑器关闭即清除。** 从浮动工具条开始评论和从引用列表打开评论采用同一规则；切换编辑条目时先清除上一条。列表打开、悬停或草稿中仍有引用，不单独触发高亮。Diff 暂不高亮；重启后恢复的引用仍可编辑评论，但不恢复来源高亮。

来源位置是会话内的临时显示关联，以附件 ID 连接到原来源，不写入 `DraftFile`、发送文本或 Pi 历史。捕获必须发生在来源选区仍可读取时，覆盖工具条、右键菜单和命令面板入口：

- **对话：**保存消息身份及具体正文段身份、Markdown 源范围（UTF-8 字节范围）和捕获时已提交解析内容的版本标识。仅角色或选中文本不能定位消息；同一消息的不同正文段也不能混用范围。
- **源码：**保存文件身份（含所属会话及路径）、当前预览的加载版本和准确字节范围。行号用于来源标题，不能替代部分行选区的字节范围；同路径重新加载不自动视为同一版本。

临时关联由该会话的 UI 拥有，不延长来源组件寿命。只有当前显示会话、附件仍存在、来源身份及内容版本仍匹配时才绘制。消息重新解析或流式更新导致版本变化、文件重新加载、来源组件替换或卸载、范围无法映射时，静默不高亮；不搜索相同文字、不猜偏移、不重新读取磁盘、不自动跟踪内容变化。关闭评论、切换会话、删除引用或成功消费引用时清除；失败保留附件不等于持续保留高亮，仍以评论编辑器是否打开为准。

**对话与查找共用一个高亮写入方。** `TextViewState::set_range_highlights` 接受渲染文本范围，须从当前 `rendered_text()` 用 `range_for_source` 转换已验证的源范围；转换失败就省略引用高亮。引用与查找不能各自调用 `set_range_highlights` / `clear_range_highlights` 覆盖对方。统一合成顺序为 **quote < find < current find**，后者覆盖前者；关闭评论只移除 quote 层，关闭查找只移除 find 层。现有查找的重绘缓存也须考虑引用层变化，不能因查找结果未变而跳过合成。

**源码使用 Editor 的公开 `RangeDecorationCollection`。** 为引用持有独立集合，以 `RangeDecorationStyle::Fill` 填充已验证的字节范围，不借用 selection 或 diagnostics。关闭编辑时清空，释放来源关联时显式 dispose；仅丢弃集合句柄不会清除装饰。Kit 随文本编辑调整装饰的能力不作为快照仍有效的依据，加载版本失效时直接撤掉。

高亮采用主题派生的淡色，与查找和真实选区区分；列表中的来源标题与评论编辑状态仍提供非颜色提示。本次高亮增量不实现来源气泡；用户已另行确认在 Kit 公开能力到位后增加可点击的来源标记，点开该条引用的评论编辑器。它可以与高亮分期，但不是可有可无的装饰。不新增回跳出处、变化提示或长期标注数据。

此增量需要验证的产品失败是来源串位、关闭后残留及覆盖查找结果。按 AGENTS.md 优先扩展现有正式引用/查找组件回归，观察编辑开启与关闭时的实际高亮以及来源失效后的清理；仅现有入口无法覆盖独有契约时才新增少量测试。不测试 Kit 的范围映射或装饰实现本身，不按来源与关闭方式排列全量测试矩阵。本段为新增设计的验证要求，不表示已有实现或验收结果。

## 发送与格式

所有发送**会话草稿**的路径在同一提交边界取快照，组合“按添加顺序的引用块（每块后紧跟其评论）+ 草稿文本”。普通发送、临时窗口 `send_draft`、运行中的 steer/follow-up 或队列、模板草稿均不能各自拼接或遗漏引用。模板/技能等已有正文处理保持语义，引用在其正文准备完成后追加，不作为模板参数或命令名再次解析。已有图片附件仍走原路径。

非草稿的显式命令输入不隐式挪用当前会话附件；模板或队列只消费它们所属的草稿快照。队列捕获组合后的普通文本，后续编辑或重试不能重复追加引用，也不能把另一份草稿的引用带进去。

**斜杠命令与引用（已确认）：**需要 Pi 分派或展开的草稿——扩展命令、`/skill:name`、直接 prompt 命令，以及仍以 `/name 参数` 形式发送的 pending_template——与引用同时存在时，本次不提交，提示“此命令暂不支持附带引用。请改写为普通消息，或移除引用后发送。”，正文、图片、引用和评论全部保留。不自动展开、不剥离命令、不移除引用、不拆成两次发送、不把引用作为命令参数。原因：Pi 的命令/模板/技能展开作用于整条 `message` 字符串，RPC 只有 `message` + `images`，没有分段或“只追加上下文”的入口；拆成两条会改变回合语义且无法原子撤销。已经由现有流程得到普通正文、无需 Pi 命令展开的情形照常走普通路径。将来自建富文本输入框（#104）可明确命令与引用的前后结构，届时再评估。

只有引用、没有正文时**允许发送**，仍须满足既有连接、模型、草稿可编辑和提交条件；不能继续仅凭 `draft.text().trim().is_empty()` 禁用发送或忽略草稿保存。引用不自动发送，也不绕过 Pi 状态限制。

提交被拒绝或失败时保留正文、图片和引用，可由用户继续编辑或重试。成功指现有发送入口接受该次提交（或既有队列接纳），不是等待模型完整回答；成功后消费该次快照的引用和正文，沿用 revision/身份保护，不清掉提交期间新产生的草稿。模型稍后返回错误是会话内容，不把已经发送的引用自动重新加入草稿。

组合时保留正文原有内容，只补足相邻段之间的空行。无评论的引用不输出评论行。重复引用按原顺序逐条发送。标题注明“选中时的内容” / “Content at selection”；对话使用真实角色与 Markdown 引用块，文件/Diff 使用来源标题和围栏代码块：
