# Pi 设置的剩余工作

当前覆盖以[配置清单](coverage.md)及[项目文件管理](../project-pi-files/README.md)为准。本页仅保留后续工作的边界，不重复已经完成的 D1/D2/D3 方案。

| 工作 | 当前成果 | 剩余内容 |
| --- | --- | --- |
| 项目 `.pi/` 管理 | 部分 settings 字段、文本资源编辑、项目包安装/移除、独立扩展/主题及显式资源路径只读展示 | 资源路径数组写入、资源启停/过滤和 delta 编辑、扩展/主题编辑深度；项目包更新仍待验证 |
| 其他全局 Pi 配置 | 对话/网络基础字段及资源管理 | Provider/认证、自定义模型、工具与运行环境、模型覆盖及高级项 |
| MCP | 完成部分配置契约研究 | 全局/项目 MCP 配置和认证 UI，保存/连接与替代扩展识别等设计 |

三项工作独立选择范围，不将所有设置都并入项目配置。项目工作仅指项目 `.pi/` 下文件；`.pi/mcp.json` 归 MCP，项目外 AGENTS/CLAUDE/祖先资源与全局 trust.json 记录管理不属于该工作。

## 保留的技术问题

- Pi 的 update 无项目专用作用域；重新 install -l 能否可靠完成仅项目更新仍需验证，不提供移除后安装的替代方案。
- MCP 的部分覆盖、运行时注册和完整定义有不同规则；第三方扩展可能替代内置 MCP，识别方法待验证。
- Pi 对 mcp.json 的原地写入不使用 settings 锁，需独立设计写入冲突契约。
- --no-session 不证明模型查询没有扩展启动或 MCP 连接副作用；当前模型发现需要扩展模型，尚不能声称无副作用。

后续优先级按使用需求确定，没有将剩余项全部授权实现。
