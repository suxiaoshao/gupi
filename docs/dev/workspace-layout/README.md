# 主窗口工作区、历史面板与标题栏

状态：已实现，工作树待用户试用。本方案替换 [会话与源码工作区](../issue-31/ui-redesign.md) 中的主窗口布局、右侧导航与窄窗口规则，以及 [#33](../issue-33/README.md) 改动卡片的原地展开；文件读取边界、源码预览能力、改动合成逻辑和每个对话独立的文件树/源码状态保持不变。

标签与标题栏的结构调整、细节审查及验证见 [工作区面板结构调整与界面细节重设计](panel-polish.md)。

## 目标与问题

改造前主窗口为 **[会话侧栏] [会话] [源码分栏] [历史 | 文件 导航]**：

- 文件树与历史共用一个页签位置，浏览文件要先切走历史；源码打开在导航之外的独立分栏，右侧实际上有两种形态不同的区域。
- 空间不足以停靠导航时，导航变为覆盖层，从中打开文件会关闭覆盖层（`crates/gupi-conversation-ui/src/home/workspace.rs` 的 `open_source`），无法连续浏览。约在窗口宽度低于“左栏 + 54rem + 15rem”时触发，常见笔记本宽度都会遇到。
- 本轮改动在回复下方原地展开差异，长差异撑长消息流；同一时间难以对照多轮改动。
- 标题栏右侧四个按钮中三个是低频会话操作，“项目 Pi 设置”与会话菜单重复；面板按钮标为“右侧面板”却恢复上次页签，“历史”“项目文件”命令各自强制切页签。

目标：

- 右侧只有一个内容区域，并以标签承载文件、各轮改动，以后承载 Git 等工具。
- 文件和改动都能连续浏览：在导航或列表中切换条目不关闭任何面板。
- 历史作为对话自身的导航随对话栏布局；所有可停靠面板遵循同一条空间规则。
- 标题栏按对话与工作区分段；工作区段承载标签，低频会话操作集中到会话菜单。

不做：Git 标签、跨轮合并的整体改动、文件“固定为标签”、编辑与保存、浏览器标签、从聊天消息打开文件的新入口、标签跨重启恢复、临时窗口的任何布局或宽度变化。

## 参考

- VS Code 1.135 Agents 窗口（`src/vs/sessions/`，tag `1.135.0`）：会话列表、聊天与一个侧面板；侧面板含共享编辑器标签栏和右侧停靠的上下文详情（文件时为 Explorer，差异时为改动文件列表）。从 Explorer 选择文件在同一编辑区打开且树保持；一个总开关恢复整个组合，内部可收起详情、最大化；窄时先压缩编辑内容，不关闭树。
- Cursor 3.x Agents Window：文件、浏览器、变更作为聊天旁编辑面板中的标签，可全屏。官方材料未说明树在每次打开后是否保持及窄窗口规则，不作依据。

## 设计

### 区域与职责

```text
宽窗口，历史固定、工作区打开
┌──────────┬───────────────────────────┬──────────────────────────────────┐
│ 会话侧栏 │ 标题 ⋯             历史   │ 文件 × │ 改动 × │ + │ 最大化 开关│
├──────────┼───────────────────────────┼──────────────────────────────────┤
│          │                    │ 历史 │                                │
│          │   会话正文（居中） │ 面板 ├─────────────────────┬────────────┤
│          │                    │      │ 主内容              │ 导航       │
│          │   输入框           │      │ （源码 / 差异）     │（树/列表） │
└──────────┴───────────────────────────┴─────────────────────┴────────────┘
            ←──────── 对话栏 ─────────→ ←────────── 工作区 ──────────────→
```

| 区域 | 职责 | 显示控制 |
| --- | --- | --- |
| 会话侧栏 | 选择对话 | 用户开关，不因其他面板自动收起（不变） |
| 对话栏 | 会话正文、输入框；历史面板挂在其右侧 | 工作区最大化时临时隐藏 |
| 工作区 | 当前对话的标签：文件、各轮改动 | 标题栏工作区按钮 |

主窗口的会话正文与输入框最大宽度 `Wc` 改为一个设计值（当前写在 `home/content.rs`、`home/composer.rs`、`home/messages.rs` 的 820px），以 rem 表示，数值在设计校验时确定。它只属于主窗口组合：共享的消息与输入框渲染函数由调用方传入宽度策略，临时窗口保持现有 820px 及空会话 780px 包裹不变。

### 工作区标签

每个标签由**主内容**和右侧**导航**组成，导航可由用户按标签收起：

| 标签 | 类型 | 主内容 | 导航 |
| --- | --- | --- | --- |
| 文件 | 可关闭，同一对话最多一个 | 源码预览；未打开文件时没有主内容 | 项目文件树（未打开文件时始终显示） |
| {回复摘要} | 改动标签，可关闭 | 所选文件的差异 | 这一轮改过的文件 |

- `+` 打开启动器式“新标签页”；工具包括文件与最近一轮变更，下面列出本对话最近打开的文件和改动（最多 8 项，不跨重启）。选择工具替换当前新标签页；再次打开已有工具激活已有标签。所有标签关闭后保留一个新标签页，工作区不隐藏。以后的 Git 等工具从启动器加入，本轮不实现。
- **文件标签**：在树中单击或 Enter 打开文件，只替换预览（沿用 #31 的单击保留树焦点、Enter 聚焦源码）。每个对话仍只有一个源码槽，关闭文件（×）回到只有树。“在文件中显示”切到文件标签、必要时展开树并定位。
- **改动标签**：一轮回复（现有 Run）对应一个标签。点击某轮改动卡片中的文件行，打开或激活该轮标签并选中该文件；在列表中选择其他文件只切换差异，列表保持。差异沿用 GPUI Kit 只读差异组件与 #33 的合成结果、“写入”中性显示、错误标记与统计；差异标题提供“打开文件”，切到文件标签打开该文件。回复进行中标签原地更新，结果不变时保留滚动与选择。
- **改动标签的身份与生命周期**：
  - 投影出的 Run ID 会在持久化后变化（`home/messages.rs` 的 Run 投影），标签身份沿用改动卡片的做法，经工具调用 ID 迁移（`home/messages/changes.rs` 的 `sync`）；迁移保持标签顺序、当前标签和所选文件。
  - “可见范围”与“删除”分开判断。`EditedFiles` 只反映当前投影，且会丢掉全部净零的 Run（`edited_files.rs`），不能把“不在 `EditedFiles` 中”当作删除。标签所属工具调用仍在会话记录中、但不在当前分支或历史预览范围内时，标签保留并显示“此回复不在当前范围”，提供关闭；回到范围内恢复内容。只有这些工具调用已不在会话记录中时，标签才自动关闭。
  - 本轮所有文件净变化为零时，标签保留并显示“本轮改动已全部抵消”；所选文件因净零或范围变化消失时，选中下一个文件（末尾时取剩余最后一个），焦点只在原本位于该文件时随之移动。
- **标签标题**：取开启该 Run 的用户消息首行并截断，用户消息为空时显示回复时间；提示中显示完整文字、时间与净 `+a −b`。
- **标签栏**：基于 GPUI Kit Base Tab 在应用中组合圆角桌面标签，支持拖动排序、中键关闭和“关闭 / 关闭其他 / 关闭右侧”菜单；Files 也参与关闭和排序。关闭当前标签激活左侧标签，没有左侧时激活剩余首项；全部关闭回到新标签页。横向滚动、当前标签自动显示与全部标签菜单保留；键盘支持左右、Home/End 和 Enter/Space，不新增全局快捷键。关闭按钮保留固定操作槽，选中、悬停和键盘焦点时显示，标题不跳动。
- **所有权**：每个对话拥有自己的标签列表、当前标签和各标签状态（导航收起、选择、滚动），切换对话使用各自实例；不持久化到磁盘。

### 历史卡片样式

历史面板在既有分配区域内使用统一 `p_2` 内边距，呈现脱离窗口上、右、下边缘的圆角卡片；不改变停靠阈值、正文位移或面板宽度计算。共用主题 `popover` / `popover_foreground`、细边框和 `radius_lg`，停靠不加阴影，浮窗在同一卡片上增加阴影。圆角约束内部内容，外侧调整宽度的命中区域保持可用；静止时不绘制额外的整高分隔线，悬停与拖动沿用组件反馈。

标题行仅显示“历史”和一个 ⋯ 菜单；菜单依次包含列表/树、内容程度与分支范围，沿用原有选中状态与语义（树模式不显示仅供列表使用的分支范围）。不增加会话摘要或其他内容。

### 改动卡片

主窗口卡片头采用圆角弱化底色的差异图标小块、两行摘要（文件数、净 `+a −b`）及右对齐的描边“查看变更”按钮。按钮打开或激活该 Run 的 Changes 标签并选中第一个文件，使用与文件行相同的显式 ensure-visible 规则。头部下方使用细分隔线，文件行去掉展开箭头，保持悬停反馈、弱化目录、文件名与右对齐统计；底部“再显示 N 个文件 / 收起文件”配方向箭头。没有净统计的 write/回退不虚构数量，保留“写入”“错误”文字标记。

主窗口中，回复下方的改动卡片只做摘要：保留卡片头、文件行（目录弱化、文件名强调、“写入”“错误”标记、净统计）以及“再显示 N 个文件 / 收起文件”。文件行不再原地展开，改为在工作区打开对应改动标签；无障碍名称说明“在工作区中打开”。#33 中原地展开、展开后滚动与焦点保持的规则随之删除，净零文件消失时的焦点规则保留。工具详情对话框中的差异不变。临时窗口没有工作区，同一卡片在临时窗口中保留现有原地展开及其状态，不受本节影响。

### 固定与浮窗

历史面板和工作区各有两个状态：

- **固定**：用户希望面板占用布局空间的持久偏好。
- **浮窗**：临时打开的覆盖层，不改变固定偏好。

固定且能停靠时停靠显示；固定但不能停靠时不显示，偏好保留，对应按钮改为开关浮窗；空间恢复后固定的面板自动重新停靠，此时已打开的该面板浮窗随之关闭。未固定的浮窗不因空间变化而停靠或关闭。窗口缩放、面板切换和字号变化不改写固定偏好。

操作分两类：

- **显式打开**：从面板外发起的打开命令，包括标题栏按钮打开、“打开历史”“项目文件”“聚焦源码”、点击改动卡片文件行或“查看变更”。先确定目标标签与内容，再按其要求判断：能停靠时设为固定并停靠（已打开的浮窗随之关闭）；不能停靠时打开或保留浮窗，不改固定偏好。
- **面板内导航**：在已可见的面板内进行的操作，包括切换或关闭标签、在导航中打开条目、展开导航、“在文件中显示”、历史条目选择。保持当前停靠或浮窗形态与固定偏好，只按下文“工作区内容变化时的过渡”处理空间变化。

同一时间最多一个浮窗，打开一个会关闭另一个。浮窗内的点击、选择、展开、切换标签、滚动不关闭浮窗；Escape、再次点击按钮或点击浮窗外区域关闭它。工作区浮窗使用覆盖层表面与阴影，停靠时只用一条细分隔线；历史停靠与浮窗共用上文的内缩卡片，只有浮窗加阴影。

### 空间分配

设 `A` 为扣除可见会话侧栏后的宽度，`s` 为分隔线宽度。先分配工作区，再在得到的对话栏宽度 `C` 内分配历史面板。几何为纯函数，渲染和拖拽共用同一套边界；显示宽度不回写偏好，延续当前拖拽中断不保存、主动结束才保存的语义（`home/panes.rs`）。

所有夹取沿用当前 `sidebar_bounds` 的做法：上限不小于 0，下限大于上限时降到上限；保存值低于下限或高于上限时只影响显示宽度，不改写偏好。

**工作区**按当前标签的内容计算。工作区标签栏占用高度，不影响宽度。导航宽度 `T` 取自保存值（`navigator_width_rem`，改为工作区导航宽度，各标签共用），只在导航可见时计入；`Cmin`、`Tmin`、`Pmin` 分别为会话、导航、主内容最小宽度；`r` 为 `source-split.toml` 中的会话比例，含义保持为“会话 /（可用宽度 − 可见导航宽度）”，各标签共用。

| 当前标签内容 | 能停靠条件 | 停靠时宽度 |
| --- | --- | --- |
| 只有导航（文件标签未打开文件） | `A − s ≥ Cmin + Tmin` | `T` 夹取到 `[Tmin, A − s − Cmin]`；`C = A − T − s` |
| 主内容 + 导航 | `A − 2s ≥ Cmin + Tmin + Pmin` | `T` 夹取到 `[Tmin, A − 2s − Cmin − Pmin]`；令 `R = A − T − 2s`，`C = clamp(r × R, Cmin, R − Pmin)`，主内容取 `R − C` |
| 只有主内容（用户收起导航） | `A − s ≥ Cmin + Pmin` | 令 `R = A − s`，`C = clamp(r × R, Cmin, R − Pmin)`，主内容取 `R − C` |
| 浮窗或不显示 | — | `C = A` |

拖动会话与主内容之间的分隔线时 `r = C / R`；拖动导航分隔线时更新 `T`。

**浮窗中的工作区**：从窗口右缘覆盖对话栏，宽度 `Wo = max(0, A − K)`，`K` 为左侧保留的一条会话区域（设计值，用于点击关闭；`A` 不足时按比例缩小，保证浮窗可用）。只有导航时导航宽为 `clamp(T, Tmin, Wo)`；有主内容且导航可见时导航宽为 `clamp(T, Tmin, Wo − s − Pov)`，主内容取 `Wo − 导航宽 − s`；导航收起时主内容取 `Wo`。`Pov` 是浮窗中主内容的可用宽度下限（设计值，小于 `Pmin`），同样按上述规则在空间不足时降低，主内容不会为零或负宽度。

**历史面板**。设 `P` 为历史面板宽度（独立偏好），`g` 为正文与面板的间距，`Wmin` 为正文可读最小宽度（设计值）。能停靠条件为 `C − P − g ≥ Wmin`。停靠时：

```text
B      = min(Wc, C − P − g)              // 正文宽度
origin = min((C − B) / 2, C − P − g − B) // 正文左缘
```

空白足够时正文保持在对话栏中居中，面板放在右侧空白；空白不足时正文右缘贴近面板并随宽度连续移动，两种情况在边界 `C = Wc + 2(P + g)` 处位置相同，不发生跳动。正文与输入框共用同一位置。不能停靠时，历史浮窗贴对话栏右缘、占对话栏高度，宽度为 `clamp(P, Pmin_h, C)`（同样按上述夹取规则）。

历史在每次布局时按最终的 `C` 重新判断：工作区变为不显示或浮窗后 `C` 变宽，固定的历史可以因此重新停靠，这是预期行为。

### 工作区内容变化时的过渡

工作区当前标签或其内容改变时（打开或关闭文件、展开或收起导航、“在文件中显示”、切换标签、关闭标签后激活其左侧标签、批量关闭或 Run 删除导致的自动关闭），先确定结果标签及其内容，再按其实际要求判断。在停靠的工作区里，若要求提高且新内容不能停靠：工作区不隐藏，直接转为浮窗显示新内容，焦点按该操作的规则进入（打开文件沿用 #31；展开导航与“在文件中显示”进入导航；打开改动标签进入其差异）；固定偏好不变，空间够时按固定规则恢复停靠。在已是浮窗的工作区里执行这些操作，浮窗保持。隐藏的工作区内容变化不会使其显示。Run 删除等非用户操作导致的变化不移动焦点，除非焦点原在被移除的内容中。导航只由用户收起，不会为了满足空间被自动收起。

若结果要求不高于原来，保留工作区原有可见性：隐藏的仍隐藏；停靠的按正常规则判断；浮窗保持，只有在工作区固定且新内容能停靠时才关闭浮窗并停靠显示。这些变化不改写固定偏好。

### Escape 与焦点

按从上到下的顺序处理，前一层处理后停止：

1. 菜单、对话框、源码查找、差异内部覆盖等先关闭自己。
2. 工作区最大化时恢复普通布局，不改写宽度和固定偏好。
3. 焦点在任一浮窗内（包括其中的源码、差异、加载/错误状态、标签栏、工具栏、导航、历史列表）：关闭浮窗，焦点回到对应标题栏按钮。源码的 Escape 处理须让浮窗优先于“返回”逻辑（当前 `home/source.rs` 的 `return_focus` 总是停止传播）。
4. 停靠的源码：沿用 #31，返回停靠树中的打开行；树收起时返回输入框。停靠的差异：返回改动列表中的所选文件；列表收起时返回输入框。
5. 其余区域沿用现有行为，停靠列表中的 Escape 仍是停止回复。浮窗、源码和差异的 Escape 不触发停止回复。

关闭面板或标签时只有焦点原在其中才转移焦点，不抢走正在输入的焦点（沿用 #31 的关闭文件规则）。

### 标题栏

```text
[侧栏开关][新建*] │ 会话标题 ⋯ …… [历史] │ 标签 ×  +  …  [最大化] [工作区]
                                         * 仅侧栏收起时显示
```

- 左侧侧栏开关与侧栏收起时的新建按钮不变。
- 去掉标题前的装饰性文件夹图标；会话菜单 ⋯ 紧贴标题，属于该会话。
- 历史开关留在对话段；停靠工作区的标签、导航开关、最大化与工作区开关在同宽右段，分隔线与内容区对齐。隐藏或浮窗时没有右段，工作区开关回到对话段，浮窗标签位于浮窗顶部。标签间和空白区保留原生窗口拖动与双击行为。两个面板开关的图标为：历史用目录中可用的 Lucide `ListClock`，工作区隐藏时用 `PanelRightOpen`、可见时用 `PanelRightClose`（与左侧 `PanelLeftOpen` / `PanelLeftClose` 对应）。按钮的选中状态表示对应面板当前可见，提示显示名称与快捷键。
- 删除导出、刷新、项目设置按钮，入口移入会话菜单。运行状态由侧栏会话行的现有加载指示表达。

工作区最大化临时占用会话栏空间，会话侧栏保持用户状态。按钮或 Escape 恢复；切换对话、关闭最后一个内容标签、窗口变窄到无法停靠时退出，不保存最大化状态，不改写固定、宽度或分隔比例。浮窗不提供最大化。

### 会话菜单

标题栏 ⋯ 与侧栏会话行共用 `navigation::session_menu`，按组排列，组间用分隔线：

1. 会话信息…、导出会话为 HTML…
2. 重新连接；运行中“停止” / 空闲“关闭运行”（现有，仅已连接时）
3. 项目 Pi 设置…、显示配置文件夹、复制路径
4. 重命名…、复制会话
5. 移到废纸篓

可用性沿用各命令现有判定（导出、重新连接等不可用时禁用）。命令面板中的对应命令保留。

### 命令

| 命令 | 行为 |
| --- | --- |
| 标题栏历史按钮 / “历史” | 历史浮窗已打开时关闭浮窗，不改固定偏好；否则历史可见时取消固定并隐藏，不可见时按显式打开处理。变为可见时焦点进入历史列表，变为隐藏时按上节规则处理焦点 |
| 标题栏工作区按钮 | 同上，作用于工作区；变为可见时恢复当前标签，焦点进入其可见内容（导航可见时进入导航，否则进入主内容） |
| “项目文件” | 打开或激活唯一的文件标签后按显式打开处理，焦点按上一行规则 |
| “打开历史” | 按显式打开处理后聚焦；已停靠时只聚焦 |
| “聚焦源码” | 有文件时打开或激活文件标签，按显式打开处理并聚焦源码 |
| “关闭文件” | 关闭当前对话的源码，按“工作区内容变化时的过渡”保留可见性 |
| “查找会话” | 关闭遮挡对话栏的浮窗，再打开会话查找 |
| “显示会话” | 删除；它只服务于被移除的单正文槽，回到会话由关闭浮窗完成 |

### 状态所有权与偏好

- `HomeView` 持有窗口级的固定偏好、当前浮窗和布局几何；每个 `SessionView` 持有自己的标签列表与当前标签、文件树、源码实体、各改动标签的差异状态和订阅。改动标签读取该对话已有的 `EditedFiles` 结果，不另建数据源。
