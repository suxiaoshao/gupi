# 项目 `.pi/` 文件管理

状态：D1 已完成受影响检查和主要 UI 路径验证，可交付试用；D2 处于契约调研阶段，尚未开始实现。D1、D2 是同一工作内的实施阶段，均不代表整个 `.pi/` 管理范围完成。

## 目标与文档

在 Gupi 中维护某个项目 `.pi/` 下的配置及资源，明确实际写入目录、与全局文件的关系及信任状态。修改属于项目，不属于某个对话独有的设置。

- [界面与操作流程](interface.md)：入口、作用域、来源展示、编辑及离开流程。
- [数据与写入规则](data-and-persistence.md)：文件归属、上游加载规则、异步请求归属、保存和包操作边界。
- [D1 实现与验证](implementation.md)：代码位置、已实现行为、差异和协调者验证结果。
- [D2 包契约调研](d2-packages.md)：Pi 命令能力、信任语义和未选定方案。
- [现有配置覆盖](../issue-2/coverage.md)：全局配置和独立 MCP 工作的对照；首批 settings 字段仍以[已有实施方案](../issue-2/implementation.md)为准。

## 已确认方向

- 项目配置指实际项目目录 `.pi/` 下的文件。`.pi/mcp.json` 归独立 MCP 工作；项目外 AGENTS/CLAUDE 指令和全局 trust.json 管理不纳入。
- 共用现有设置的 Pi 区域，通过明确的全局/项目作用域编辑；不新增对话内嵌设置面板、独立设置窗口或常驻对话齿轮按钮。
- 沿用对话 `⋯` 和项目行菜单的“项目 Pi 设置…”入口，作用域支持“选择项目文件夹…”。选择目录不自动信任，也不自动创建 `.pi/`。
- 返回原主视图/对话，保留未保存修改的保护。可作用域页面共享目标项目；仅全局页面明确标明作用域限制。

## 实施分期

| 阶段 | 交付内容 | 明确边界 |
| --- | --- | --- |
| D1 项目文本资源 | `.pi/skills/`、`.pi/prompts/`、SYSTEM.md、APPEND_SYSTEM.md 的查看、创建、编辑及适用的删除；接入现有项目 settings 与作用域流程 | 项目自有文件可写，全局来源只读并可转全局编辑；保持现有资源编辑器保存方式 |
| D2 项目包管理 | `.pi/settings.json` 中包声明、项目安装/更新/移除和来源展示 | 需先落实 cwd/agent-dir 分离、local 参数、身份去重、过滤 delta 与信任契约；不由 D1 顺带实现 |
| 待设计的项目内容 | `.pi/extensions/`、`.pi/themes/` 的管理深度，以及 settings 中资源路径数组/对全局资源的过滤 | 仍属于项目工作，尚未决定编辑深度；D1/D2 完成不代表所有 `.pi/` 能力完成 |

D1 不新增更多普通 settings 字段，不编辑扩展代码或主题代码，不添加 MCP、认证或自定义 Provider UI，不自动安装项目依赖。不在项目页提供“禁用全局资源在本项目中的使用”这类尚未设计的过滤操作。已有未知 JSON 字段和资源声明必须保留。

## 实施顺序与所有权

1. `gupi-resources`：为资源扫描和操作显式携带全局 agent-dir 与项目 cwd/作用域；输出来源与可编辑性，保持文件读取不执行扩展、不安装包。
2. `src/features/settings`：单一作用域协调现有 PiConfig 和资源控制器；补目录选择、请求切换、异步旧结果隔离和草稿保护。资源编辑器继续使用现有表单/弹层，不新增竞争的保存入口。
3. 接入 D1 Skill/提示词及系统提示词；入口继续由 conversation-ui 派发项目路径，根应用组合负责导航。九种语言同步维护用户文案。
4. 完成 D1 受影响检查和主要路径验证后交付；按反馈继续。D2 在包契约核对完成后设计并实施，不提前实现半工作的项目包模式。

不升级固定 gpui 依赖，不搬迁能力 crate，不引入新的通用状态层。

## 验证与交付条件

验证由协调者执行；设计师负责源代码实现。以下为验证范围；实际结果见 implementation.md。

- 纯文件/状态回归：两个项目之间隔离；全局文件不被项目操作修改；切换后晚到结果不能覆盖新目标；缺失目录与读失败不同；创建不覆盖已有文件；保存失败或冲突保留草稿。
- 资源规则：SYSTEM/APPEND 同名文件优先与信任；Skill/Prompt 名称和碰撞诊断；符号链接/外部路径符合选定写入契约。测试使用临时目录，不启动真实 MCP、安装包或读取凭据。
- 按变更运行资源 crate 与根包受影响测试、必要构建、格式和 Clippy；不得把此前首批测试结果算作此功能验证。
- 实际窗口：从对话进入对应项目；无对话时选文件夹；创建/编辑一种 Skill 与模板、修改系统提示词；切换项目或返回时验证保存/放弃/取消；未信任项目的可编辑/未加载状态明确。验证范围按 D1 受影响流程收敛。
- D2 另列项目包安装等外部操作的临时环境验证，不把网络安装混入 D1 必要检查。
