# D3 项目资源可见性：界面与验证

状态：已实现。协调者负责实现、测试与 UI 验收，设计师负责源码 review。D1 的作用域、信任和编辑规则见[界面设计](interface.md)，D2 的包规则见 [D2 界面](d2-interface.md)，本文不重复。

## 范围

| 内容 | 处理 |
| --- | --- |
| `.pi/extensions/`、`.pi/themes/` 中的独立资源 | 只读显示 |
| 项目 `settings.json` 中 `extensions`、`themes`、`skills`、`prompts` 数组列出的普通路径 | 只读显示 |
| 项目作用域下继承的全局独立扩展 | 只读显示 |
| 全局独立主题 | 不显示，全局和继承组都不显示；不新增全局主题开关 |
| 已停用的资源 | 显示“已停用”，不提供开关 |
| `.pi/skills/`、`.pi/prompts/` 自动发现的文件 | 保持 D1 的编辑能力，不变 |

**不提供**：

- 开关，以及写入项目过滤项或 `autoload: false`；
- 扩展或主题的代码编辑器；
- 项目包更新；
- MCP、认证和高级设置；
- 祖先目录 `.agents/skills`、AGENTS 文件和信任记录的管理。

## 扫描规则

- **只读文件**：扫描不执行扩展、不安装依赖、不启动 Pi 或 npm，也不写入任何文件。
- **自动发现与全局扫描一致**：
  - 扩展：`.pi/extensions/` 下的 `.ts`/`.js` 文件和扩展目录；
  - 主题：只看 `.pi/themes/` 顶层的 `.json` 文件。
- **路径数组**：
  - 普通路径相对于 `.pi/` 解析，列出对应的资源。
  - 含 `*`、`?` 或以 `+`/`-`/`!` 开头的条目是模式，沿用现有扫描的过滤语义，只决定已列出资源是否启用，不用来展开发现新文件。界面不承诺支持任意模式的编辑或预览。
- **同一文件只占一行**：按真实路径去重，与全局扫描一致。文件同时被路径数组列出、又在 `.pi/skills/` 或 `.pi/prompts/` 中被自动发现时，**保留 D1 的编辑能力**。
- **停用状态**：沿用全局扫描对各来源的判定，包括项目覆盖项、路径数组中的模式和包条目过滤。
- **路径不存在**：列出的路径不存在时，扫描跳过该条目，不显示专门的警告。文件无法读取时，沿用现有扫描的诊断行为。

## 行的类型

| 行 | 标记 | 操作 |
| --- | --- | --- |
| 本项目自动发现的 Skill / 模板（`.pi/skills/`、`.pi/prompts/`） | D1 现有标记 | D1 现有操作，另加“复制路径” |
| 本项目独立扩展、主题（`.pi/extensions/`、`.pi/themes/`） | “本项目”，只读 | 显示位置、复制路径 |
| 路径数组列出的资源，位于 `.pi/` 内但不在可编辑目录中 | “本项目”，只读 | 显示位置、复制路径 |
| 路径数组列出的资源，位于 `.pi/` 外，或经符号链接指向外部 | “外部来源”，只读 | 显示位置、复制路径 |
| 继承的全局独立扩展 | 来源，只读 | 显示位置、复制路径 |

**通用规则**：

- 被路径数组列出的 Skill 和模板显示在 Skills 页、模板页的“本项目”组；扩展和主题显示在包页。
- 项目作用域下的所有行都不显示开关；全局作用域保持不变，开关仍在。
- 资源停用时加“已停用”标记，适用于本项目行、继承行和包内资源。
- 项目未信任时，本项目行沿用 D1 的“未加载（项目未信任）”，可以与“已停用”同时出现。
- **来源标记**：是否位于项目 `.pi/` 内与是否可编辑分开判断。归属在扫描时确定，渲染时不访问文件系统。
- **行内顺序**：名称、标记（同一行，可换行）、路径，操作按钮在最右侧。
- 扩展和主题不显示同名关系标记：本批不核对它们在 Pi 中的冲突规则。

## 布局（包页“已安装”视图）

独立扩展和主题显示在现有包页中，复用现有的资源行。

项目作用域：

```
本项目                     ← 分组标题
  项目包…
  独立扩展                 ← 子标题
  独立主题                 ← 子标题
继承自全局                 ← 分组标题
  全局包…
  独立扩展                 ← 子标题
```

全局作用域：全局包，然后是独立扩展，没有分组标题；与 D3 之前一致。

- 子标题比分组标题弱一级（更小字号、更淡颜色），继承组中的“独立扩展”不会被看成与“继承自全局”同级。
- 某个子组为空时不显示子标题。
- 空状态按作用域区分：项目作用域显示“此项目没有包。”，不使用“个人 Pi 包”的文案；本项目已有独立资源时不显示空状态。

## 文案

- 固定词汇：“本项目”“继承自全局”“独立扩展”“独立主题”“外部来源”“已停用”“复制路径”“显示位置”。
- 不写“已加载”“生效中”，不承诺当前会话使用这些资源。
- 九种语言同步。
